## 📖 오늘 공부할 내용

<sub>📘 3과목</sub>

### 2-1. 표본 추출 방법 ⭐
| 방법 | 설명 | 비유 |
|---|---|---|
| **단순 랜덤 추출** | 모두 같은 확률로 무작위 | 제비뽑기 |
| **계통 추출** | 번호를 매겨 **일정 간격**마다 | 5번째마다 1명씩 |
| **층화 추출** | 집단(층)을 나눈 뒤 **각 층에서** 랜덤 | 학년별로 몇 명씩 |
| **군집 추출** | 집단(군집)을 나눈 뒤 **군집 자체**를 뽑아 전부 조사 | 몇 개 반을 통째로 |

> 💡 층화: 층 **내부는 비슷**, 층끼리는 다름 / 군집: 군집 **내부는 다양**, 군집끼리는 비슷

### 2-2. 척도 4가지 ⭐
| 척도 | 설명 | 예시 |
|---|---|---|
| **명목척도** | 이름·구분만 | 성별, 혈액형 |
| **순서척도** | 순서 있음 | 학년, 만족도(상/중/하) |
| **구간척도** | 간격 일정, **절대 0 없음** | 온도(℃), IQ |
| **비율척도** | 간격 일정 + **절대 0 있음** (곱셈·나눗셈 의미 있음) | 키, 몸무게, 나이 |

### 2-3. 기술통계 (데이터 요약)
- **중심**: 평균, **중앙값**(가운데 값, 이상값에 강함), 최빈값(가장 많이 나온 값)
- **퍼짐**: 분산, 표준편차(=√분산), 범위, IQR, **변동계수**(표준편차 ÷ 평균, 단위가 다른 자료 비교용)
- **모양** ⭐
  - **왜도**(좌우 치우침): 오른쪽 꼬리가 길면 왜도 > 0 → **최빈값 < 중앙값 < 평균**
    왼쪽 꼬리가 길면 왜도 < 0 → **평균 < 중앙값 < 최빈값**
  - **첨도**(뾰족함): 정규분포 기준보다 뾰족하면 첨도가 큼

## ✅ 확인 문제

**17.** 다음 중 **비율척도**에 해당하는 것은?
① 혈액형 ② 섭씨온도 ③ 만족도 순위 ④ 몸무게

<details><summary>▶ 정답 보기</summary>

**④ 몸무게** — 절대 0이 있고 "2배 무겁다"가 의미 있음. 섭씨온도는 구간척도(0℃가 "온도 없음"이 아님).
</details>

**추가.** 오른쪽 꼬리가 긴 분포(양의 왜도)에서 대소 관계로 옳은 것은?
① 평균 < 중앙값 < 최빈값 ② 최빈값 < 중앙값 < 평균 ③ 중앙값 < 평균 < 최빈값 ④ 모두 같다

<details><summary>▶ 정답 보기</summary>

**②** — 큰 값 쪽 꼬리가 평균을 오른쪽(큰 쪽)으로 끌어당김.
</details>
