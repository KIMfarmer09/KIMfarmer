## 📖 오늘 공부할 내용

<sub>📘 3과목</sub>

### 2-7. 검정 방법 고르기
| 상황 | 방법 |
|---|---|
| 한 집단 평균이 특정 값과 같은가? | **일표본 t검정** |
| 같은 사람의 전/후 비교 (다이어트 전후) | **대응표본 t검정** |
| 서로 다른 두 집단 평균 비교 (남 vs 여) | **독립표본 t검정** (먼저 등분산 검정) |
| 세 집단 이상 평균 비교 | **분산분석(ANOVA)** — F분포 사용 |
| 범주형 두 변수의 관련성 (성별 × 선호 브랜드) | **카이제곱 독립성 검정** |
| 관측 비율이 기대 비율과 맞는가? | **카이제곱 적합도 검정** |
| 정규성 검정 | **Shapiro-Wilk**, Kolmogorov-Smirnov, Q-Q plot |

- **비모수 검정** ⭐: 분포(정규성) 가정이 없을 때, **순위나 부호**를 사용
  - 부호 검정, 윌콕슨 부호순위 검정, 만-위트니 U 검정(윌콕슨 순위합), 크루스칼-왈리스 검정, 런 검정, 스피어만 순위상관

① 독립표본 t검정 ② 대응표본 t검정 ③ 카이제곱 독립성 검정 ④ 분산분석

<details><summary>▶ 정답 보기</summary>

**② 대응표본 t검정** — 같은 대상의 전/후 비교.
</details>

**20.** 다음 중 비모수 검정이 **아닌** 것은?
① 부호 검정 ② 윌콕슨 순위합 검정 ③ 크루스칼-왈리스 검정 ④ t검정

<details><summary>▶ 정답 보기</summary>

**④ t검정** — 정규분포를 가정하는 **모수** 검정.
</details>

## ✏️ 스스로 체크 (안 보고 말할 수 있으면 체크)

- [ ] 전/후 비교 → 대응표본 t / 두 집단 → 독립표본 t / 세 집단 이상 → ANOVA
- [ ] 범주형 두 변수 관계 → 카이제곱 독립성 검정
- [ ] 비모수 검정 = 순위·부호 사용 (부호, 윌콕슨, 만-위트니, 크루스칼-왈리스)
