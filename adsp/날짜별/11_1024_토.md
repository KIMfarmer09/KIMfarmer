### 3-4. 다중회귀 주의점
- **다중공선성**: 독립변수끼리 강하게 상관 → 계수가 불안정. **VIF > 10** 이면 심각 → 변수 제거, 주성분분석, 릿지 등
- **변수 선택법** ⭐
  - **전진 선택법**: 변수 없음에서 시작 → 하나씩 **추가**
  - **후진 제거법**: 전부 넣고 시작 → 하나씩 **제거**
  - **단계적 선택법**: 추가·제거 반복
  - 기준: **AIC, BIC** (작을수록 좋은 모형), BIC는 변수 많을 때 벌점이 더 큼
- **정규화(규제) 회귀** ⭐
  - **릿지(Ridge)**: **L2** 규제(계수 제곱합), 계수를 0에 가깝게 줄임 (0은 안 됨)
  - **라쏘(Lasso)**: **L1** 규제(계수 절댓값 합), 계수를 **정확히 0**으로 → 변수 선택 효과
  - **엘라스틱넷**: L1 + L2 혼합

### 3-5. 로지스틱 회귀 (분류용 회귀) ⭐
- Y가 **범주형(예/아니오)** 일 때 사용. 결과는 **0~1 사이 확률**
- **오즈(Odds)** = 성공확률 / 실패확률 = p / (1−p)
- 로짓 변환: log(오즈) = β0 + β1·X
- 해석: X가 1 증가하면 오즈가 **exp(β1) 배** 증가 ⭐
- R: `glm(y ~ x, family = binomial)`

### 보-8. 회귀분석 보충 ⭐

**더미 변수**: 범주가 **k개**면 더미 변수는 **k − 1개** (예: 봄·여름·가을·겨울 → 3개)

**잔차 그래프로 가정 확인** ⭐
| 그래프 모양 | 의미 |
|---|---|
| 0을 중심으로 **고르게 흩어짐** | 정상 |
| **깔때기** 모양 (점점 퍼짐) | **등분산성** 위배 |
| **곡선** 패턴 | **선형성** 위배 |
| Q-Q plot이 직선에서 벗어남 | **정규성** 위배 |

- R의 `plot(model)` 4개 그래프: Residuals vs Fitted(선형성·등분산), Normal Q-Q(정규성), Scale-Location(등분산), Residuals vs Leverage(**영향점** — **쿡의 거리**가 크면 영향점)
- **독립성** 검정: **더빈-왓슨(Durbin-Watson)** — **2에 가까우면** 자기상관 없음 ⭐

**R²의 함정**: 변수를 추가하면 **R²은 항상 커지거나 그대로** → 변수 수가 다른 모형 비교는 **수정된 R²** 사용

**로지스틱 회귀 출력 읽기** (예시 — 숫자는 설명용)
```
            Estimate Std. Error z value Pr(>|z|)
(Intercept)   12.040      4.510   2.670   0.0076 **
wt            -4.024      1.436  -2.801   0.0051 **
    Null deviance: 43.230  on 31  degrees of freedom
Residual deviance: 19.176  on 30  degrees of freedom
AIC: 23.176
```
- 선형회귀는 `t value`, 로지스틱은 **`z value`** 가 나옴
- wt 계수 −4.024 → wt가 1 증가하면 오즈가 **exp(−4.024) ≈ 0.018배** (= 약 98% 감소)
- Null deviance(변수 없는 모형) → Residual deviance(내 모형)로 **줄어든 만큼** 설명력이 있다는 뜻

**step() 변수 선택 출력 읽기** (예시 — 숫자는 설명용)
```
Start:  AIC=70.9
mpg ~ cyl + disp + hp + wt
       Df Sum of Sq    RSS    AIC
- disp  1     0.0     170.4  68.9
- cyl   1     ...      ...   69.5
<none>               170.4  70.9
- wt    1     ...      ...   80.2
```
- `- 변수` = 그 변수를 **뺐을 때**의 AIC. **`<none>`(그대로)보다 AIC가 작으면 빼는 게 좋음** → 여기선 disp 제거
- AIC가 더 이상 줄지 않으면 멈춤

<sub>📘 3과목</sub>

### 4-1. 시계열 ⭐
- **정상성**(stationarity) 조건: ① 평균이 일정 ② 분산이 시점에 무관 ③ 공분산이 시차에만 의존
  - 평균이 일정하지 않으면 → **차분**(바로 앞 값과의 차이) / 분산이 일정하지 않으면 → **변환**(로그 등)
- **모형**
  - **AR(p)** 자기회귀: 과거 **자기 값**으로 예측 → **PACF**가 p 이후 절단
  - **MA(q)** 이동평균: 과거 **오차**로 예측 → **ACF**가 q 이후 절단
  - **ARIMA(p, d, q)**: d = 차분 횟수. 예) ARIMA(0,1,1) → 1번 차분하면 MA(1)
- **분해 시계열** 요인 4가지: **추세, 계절, 순환, 불규칙**

### 4-2. 차원 축소
- **주성분 분석(PCA)** ⭐: 상관 있는 여러 변수를 **서로 상관없는 소수의 주성분**으로 요약
  - 주성분 개수 선택: **누적 기여율 70~90%** 또는 **Scree plot의 꺾이는 지점(elbow)** 직전
  - R 출력의 `Cumulative Proportion` 행을 보고 판단
- **다차원 척도법(MDS)**: 개체들 사이 거리(비유사성)를 2~3차원 지도에 표현. 적합도는 **Stress** 값(0에 가까울수록 좋음)

<sub>📗 보충 노트</sub>

### 보-9. 시계열 · 주성분분석 보충 ⭐

**시계열 추가 개념**
- **이동평균법**: 최근 n개 값의 평균으로 예측 (모든 값에 같은 가중치)
- **지수평활법** ⭐: **최근 값일수록 더 큰 가중치** (과거로 갈수록 지수적으로 감소). 평활 상수 α(0~1)가 클수록 최근 값을 중시
- **백색잡음**: 평균 0, 분산 일정, 자기상관 없음 → 모형의 잔차가 백색잡음이면 모형이 잘 맞은 것
- ARIMA 읽기: ARIMA(1,0,0) = AR(1) / ARIMA(0,0,1) = MA(1) / ARIMA(1,1,0) = 1번 차분 후 AR(1)

**PCA 출력 읽기** ⭐⭐
```
Importance of components:
                          PC1    PC2     PC3     PC4
Standard deviation     1.7084 0.9560 0.38309 0.14393
Proportion of Variance 0.7296 0.2285 0.03669 0.00518
Cumulative Proportion  0.7296 0.9581 0.99482 1.00000
```
| 행 | 해석 |
|---|---|
| Standard deviation | 각 주성분의 표준편차 (제곱하면 분산 = 고유값) |
| Proportion of Variance | 각 주성분이 설명하는 비율 → PC1 **73%** |
| Cumulative Proportion | 누적 → PC2까지 **95.8%** → **주성분 2개면 충분** |

**적재값(loadings) 읽기**
```
                PC1
Sepal.Length  0.521
Sepal.Width  -0.269
Petal.Length  0.580
Petal.Width   0.565
```
- PC1 = 0.521×Sepal.Length − 0.269×Sepal.Width + 0.580×Petal.Length + 0.565×Petal.Width
- 절댓값이 큰 변수(Petal.Length, Petal.Width)가 PC1에 **크게 기여**
- 주성분끼리는 **서로 상관이 없음(직교)**
- 변수 단위가 다르면 **표준화(scale = TRUE, 상관행렬 사용)** 후 PCA

<sub>📘 3과목</sub>

### 5-1. 데이터 분할과 과대적합
- **과대적합(Overfitting)**: 학습 데이터는 너무 잘 맞히는데 새 데이터는 못 맞힘 (문제집 답만 외운 상태)
- 분할 방법
  - **홀드아웃**: 학습/검증/테스트로 나눔 (예: 7:3)
  - **K-fold 교차검증**: K개로 나눠 K번 반복, 매번 1개를 검증용
  - **붓스트랩**: **복원추출**. 한 번도 뽑히지 않을 확률 ≈ **36.8%** (OOB 데이터)

### 5-2. 분류 모델 평가 — 혼동행렬 ⭐⭐ (계산 문제 필수)
| | 예측 Positive | 예측 Negative |
|---|---|---|
| **실제 Positive** | TP (맞게 양성) | FN (놓침) |
| **실제 Negative** | FP (잘못 경보) | TN (맞게 음성) |

| 지표 | 공식 | 의미 |
|---|---|---|
| **정확도** (Accuracy) | (TP+TN) / 전체 | 전체 중 맞힌 비율 |
| **정밀도** (Precision) | TP / (TP+FP) | **양성이라 예측**한 것 중 진짜 양성 |
| **재현율 = 민감도** (Recall, Sensitivity, TPR) | TP / (TP+FN) | **실제 양성** 중 맞힌 비율 |
| **특이도** (Specificity) | TN / (TN+FP) | **실제 음성** 중 맞힌 비율 |
| **FPR** | FP / (TN+FP) = 1 − 특이도 | |
| **F1 score** | 2 × 정밀도 × 재현율 / (정밀도 + 재현율) | 정밀도·재현율 조화평균 |

- **ROC 곡선**: x축 = **FPR(1−특이도)**, y축 = **TPR(민감도)**. 왼쪽 위로 붙을수록 좋음
- **AUC**: ROC 아래 면적. 1에 가까울수록 좋고, 0.5면 동전 던지기 수준
- **이익도표(Gain chart) / 향상도 곡선(Lift curve)**: 상위 등급일수록 반응률이 높은지 확인

## ✏️ 스스로 체크 (안 보고 말할 수 있으면 체크)

- [ ] 더미 = k − 1개 / 깔때기 = 등분산성 위배 / 더빈-왓슨 = 독립성(2 근처 OK)

- [ ] PCA 출력: Cumulative Proportion으로 개수 결정, 주성분끼리 상관 없음
- [ ] 정밀도 TP/(TP+FP) · 재현율 TP/(TP+FN) · 특이도 TN/(TN+FP) / ROC x축 1 − 특이도
