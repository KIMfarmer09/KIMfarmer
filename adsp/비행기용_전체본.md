# 1과목. 데이터 이해 (10문항 / 20점)

> 암기 과목입니다. ⭐ = 시험 단골. 굵은 글씨 키워드 위주로 외우세요.

## 1장. 데이터의 이해

### 1-1. 데이터의 유형
| 구분 | 설명 | 예시 |
|---|---|---|
| **정량적 데이터** | 숫자로 표현, 저장·분석이 쉬움 | 키, 온도, 매출액 |
| **정성적 데이터** | 말·글·그림 등 형태가 정해지지 않음, 분석이 어려움 | 설문 주관식 답변, SNS 글 |

### 1-2. 암묵지 vs 형식지 ⭐
- **암묵지**: 머릿속에 있어서 겉으로 드러나지 않는 지식 (예: 장인의 손맛, 김장 노하우)
- **형식지**: 문서·매뉴얼처럼 겉으로 드러나 공유 가능한 지식

**지식 전환 4단계 (SECI 모델, 노나카)** — 순서대로 외우기: **공 → 표 → 연 → 내**

| 단계 | 방향 | 뜻 |
|---|---|---|
| **공통화** (Socialization) | 암묵지 → 암묵지 | 같이 일하며 보고 배움 |
| **표출화** (Externalization) | 암묵지 → 형식지 | 노하우를 문서로 작성 |
| **연결화** (Combination) | 형식지 → 형식지 | 문서끼리 합쳐 새 문서 |
| **내면화** (Internalization) | 형식지 → 암묵지 | 문서를 읽고 내 것으로 체득 |

### 1-3. DIKW 피라미드 ⭐
아래에서 위로 갈수록 가치가 높아집니다.

| 단계 | 뜻 | 예시 |
|---|---|---|
| **D**ata (데이터) | 가공 전의 객관적 사실 | A마트 볼펜 100원, B마트 200원 |
| **I**nformation (정보) | 데이터를 가공해 **의미**를 도출 | A마트 볼펜이 더 싸다 |
| **K**nowledge (지식) | 정보를 구조화해 **내 행동**에 연결 | 가격이 싼 A마트에서 사야겠다 |
| **W**isdom (지혜) | 지식을 바탕으로 한 **창의적 아이디어** | A마트의 다른 물건도 쌀 것이다 |

### 1-4. 데이터베이스(DB)의 정의와 특징
- **정의**: 체계적으로 수집·축적하여 다양한 용도와 방법으로 이용할 수 있게 정리한 정보의 집합체
- **특징 4가지** ⭐ (통·저·공·변):
  - **통합된** 데이터 (중복 없음), **저장된** 데이터 (컴퓨터 저장매체), **공용** 데이터 (여럿이 함께 사용), **변화되는** 데이터 (계속 갱신)
- **DBMS**: DB를 관리하는 프로그램 (예: Oracle, MySQL) / **SQL**: DB에 질문(조회)하는 언어

### 1-5. 기업 내부 데이터베이스 ⭐
| 용어 | 한 줄 설명 |
|---|---|
| **OLTP** | 실시간 거래 처리 (예: 은행 입출금) — "기록" 중심 |
| **OLAP** | 다차원 분석 처리 — "분석" 중심 |
| **ERP** | 인사·재무·생산 등 **전사 자원**을 통합 관리 |
| **CRM** | **고객** 관계 관리 |
| **SCM** | **공급망**(원재료→생산→유통) 관리 |
| **BI** | 데이터를 리포트·대시보드로 보여줘 의사결정 지원 |
| **KMS** | 지식 관리 시스템 |
| **DW (데이터 웨어하우스)** | 분석용으로 모아둔 대형 창고 |
| **데이터 마트** | DW의 일부, 특정 부서용 작은 창고 |

**DW의 특징 4가지** ⭐: **주제 지향적**, **통합적**, **시계열성**, **비휘발성**(한 번 적재되면 잘 안 바뀜)

## 2장. 데이터의 가치와 미래

### 2-1. 빅데이터 정의 — 3V ⭐
- **Volume**(규모), **Variety**(다양성), **Velocity**(속도)
- 추가: **Value**(가치), **Veracity**(정확성) → 5V

### 2-2. 빅데이터가 만든 변화 ⭐ (자주 나옴!)
| 과거 | → | 현재 |
|---|---|---|
| 사전 처리 | → | **사후 처리** (일단 모으고 나중에 분석) |
| 표본 조사 | → | **전수 조사** |
| 질(Quality) | → | **양(Quantity)** |
| 인과관계 | → | **상관관계** |

### 2-3. 빅데이터의 가치 산정이 어려운 이유 ⭐
1. **데이터 활용 방식**: 재사용·재조합·다목적 활용 → 누가 어디에 쓸지 모름
2. **새로운 가치 창출**: 기존에 없던 가치를 만듦
3. **분석 기술의 발전**: 지금은 가치 없는 데이터도 나중에 가치가 생김

### 2-4. 빅데이터 활용 기본 테크닉 ⭐ (사례 ↔ 기법 연결 문제)
| 기법 | 사례 키워드 |
|---|---|
| **연관규칙 학습** | "커피 사는 사람이 탄산음료도 많이 사는가?" |
| **유형 분석(분류)** | "이 사용자는 어느 그룹에 속하는가?" |
| **유전 알고리즘** | "최적의 택배 차량 배치", 진화·최적화 |
| **기계 학습** | "시청 기록으로 영화 추천" |
| **회귀 분석** | "나이가 구매 차량 종류에 영향을 주는가?" |
| **감정 분석** | "새 제품에 대한 고객 평가는 긍정?부정?" |
| **소셜 네트워크 분석** | "고객 간 관계망에서 영향력 있는 사람은?" |

### 2-5. 빅데이터 위기 요인과 통제 방안 ⭐
| 위기 요인 | 통제 방안 |
|---|---|
| **사생활 침해** | 개인정보 제공자의 "동의제" → 사용자의 **"책임제"** 로 |
| **책임 원칙 훼손** (예측만으로 처벌) | 결과 기반 책임 원칙 고수 |
| **데이터 오용** (잘못된 분석) | **알고리즈미스트**(알고리즘 해석·피해 구제 전문가) 도입 |

### 2-6. 데이터 가치 패러다임 변화
**Digitalization(디지털화) → Connection(연결) → Agency(에이전시: 연결을 효과적으로 관리)**

## 3장. 가치 창조를 위한 데이터 사이언스와 전략 인사이트

### 3-1. 데이터 사이언스
- 데이터로부터 의미 있는 정보를 추출하는 학문. 통계학보다 넓은 개념(정형 + 비정형 데이터 모두).
- 구성 요소: **Analytics**(분석) + **IT**(데이터 처리) + **비즈니스 분석**

### 3-2. 데이터 사이언티스트의 역량 ⭐
| Hard Skill | Soft Skill |
|---|---|
| 빅데이터에 대한 이론적 지식 | **통찰력 있는 분석** (창의적 사고, 호기심) |
| 분석 기술에 대한 숙련 | **설득력 있는 전달** (스토리텔링, 시각화) |
| | **다분야 간 협력** (커뮤니케이션) |

> 💡 함정: "시각화"는 Soft Skill(설득력 있는 전달)에 속합니다.

### 3-3. 개인정보 비식별화 기법 ⭐
| 기법 | 예시 |
|---|---|
| **가명 처리** | 홍길동 → 임꺽정 |
| **총계 처리** | 개인 키 대신 "평균 키 170cm" |
| **데이터 삭제** | 주민번호 뒷자리 삭제 |
| **데이터 범주화** | 나이 27세 → 20대 |
| **데이터 마스킹** | 홍길동 → 홍○○ |

### 3-4. 데이터 3법 (2020년 개정)
- **개인정보 보호법, 정보통신망법, 신용정보법**
- 핵심: **가명정보** 개념 도입 → 동의 없이도 통계·연구·공익적 기록 보존 목적으로 활용 가능

### 3-5. 전략 인사이트
- 단순히 분석을 잘하는 것보다 **비즈니스 핵심 가치에 집중**하는 것이 중요
- 일차적인 분석(부서 단위 업무 개선)에서 → **전략적 통찰**(전사 경쟁력)로 나아가야 함
- 빅데이터 회의론의 원인: 과거 CRM 실패 경험, 성과 없는 투자 → "데이터 양보다 **분석적 사고**가 중요"

① 스토리텔링 ② 시각화 ③ 분석 기술 숙련 ④ 다분야 간 협력

**Q8.** 나이 "27세"를 "20대"로 바꾸는 비식별화 기법은?
① 가명처리 ② 총계처리 ③ 데이터 범주화 ④ 데이터 마스킹

## ✅ 1과목 정답·해설

- **Q1.** **② 표출화** — 머릿속 노하우(암묵지)를 문서(형식지)로 꺼내 "표출"하는 단계. 순서: 공통화→표출화→연결화→내면화
- **Q2.** **② Information** — 두 가격 데이터를 비교해 **의미**를 도출했으므로 정보. "그럼 A마트에서 사야지"는 지식.
- **Q3.** **③ 휘발성** — DW는 **비휘발성**(한 번 적재된 데이터는 삭제·변경이 거의 없음)이 특징.
- **Q4.** **③** — 반대입니다. **질 → 양**으로 변화했습니다.
- **Q5.** **② 기계 학습** — 과거 데이터로 학습해 예측·추천. 유전 알고리즘은 "최적화" 키워드.
- **Q6.** **③ 알고리즈미스트** — ①은 사생활 침해, ②는 책임 원칙 훼손에 대한 대책.
- **Q7.** **③** — 분석 기술 숙련, 빅데이터 이론 지식은 **Hard Skill**.
- **Q8.** **③ 데이터 범주화** — 구체적 값을 범위(범주)로 바꿈.

# 2과목. 데이터 분석 기획 (10문항 / 20점)

> 암기 과목입니다. 특히 **표로 된 분류(사분면, 단계 이름)** 가 그대로 문제로 나와요. ⭐ = 시험 단골.

---

## 1장. 데이터 분석 기획의 이해

### 1-1. 분석 주제 유형 4가지 ⭐⭐ (매회 출제 수준)
**분석 대상(What)** 을 아는지 × **분석 방법(How)** 을 아는지로 나눕니다.

| | 분석 대상 **안다** | 분석 대상 **모른다** |
|---|---|---|
| 분석 방법 **안다** | **최적화** (Optimization) | **통찰** (Insight) |
| 분석 방법 **모른다** | **솔루션** (Solution) | **발견** (Discovery) |

> 💡 외우는 법: 둘 다 알면 "최적화", 둘 다 모르면 "발견". 대상만 알면 방법(솔루션)을 찾고, 방법만 알면 통찰을 얻는다.

### 1-2. 목표 시점별 분석 기획
| 과제 중심적 접근 | 장기적 마스터 플랜 |
|---|---|
| 당면 과제를 **빠르게** 해결 (**Quick-Win**) | 지속적인 분석 문화 내재화 |
| Speed & Test, 문제 해결(Problem Solving) | Accuracy & Deploy, 문제 정의(Problem Definition) |

### 1-3. 분석 기획 시 고려사항
1. **가용 데이터** (데이터 유형 파악: 정형/반정형/비정형)
2. **적절한 활용 방안과 유즈케이스** (기존 사례 활용)
3. **장애 요소에 대한 사전 계획** (비용, 정확도, 교육 등)

---

## 2장. 분석 방법론 ⭐

### 2-1. 방법론 모델
- **폭포수 모델**: 단계를 순서대로, 이전 단계 완료 후 다음 단계 (하향식)
- **프로토타입 모델**: 일단 빠르게 만들어 보고 고객 피드백으로 개선 (상향식)
- **나선형 모델**: 반복하며 점진적 개발 (위험 관리에 유리, 복잡할 수 있음)

### 2-2. KDD 분석 방법론 (5단계) ⭐
**데이터셋 선택 → 데이터 전처리 → 데이터 변환 → 데이터 마이닝 → 결과 해석 및 평가**

> 💡 "잡음·이상치·결측치 처리"는 **전처리**, "차원 축소·변수 선택"은 **변환** 단계

### 2-3. CRISP-DM 방법론 (6단계) ⭐
**업무 이해 → 데이터 이해 → 데이터 준비 → 모델링 → 평가 → 전개**

- 4레벨 구조: **단계(Phase) → 일반화 태스크 → 세분화 태스크 → 프로세스 실행**
- 단계 간 **피드백(되돌아가기)** 이 가능
- 💡 "모델 과적합 문제 확인"은 **모델링** 단계, "모델이 업무 목적에 맞는지 평가"는 **평가** 단계

### 2-4. 빅데이터 분석 방법론 (5단계) ⭐
**분석 기획 → 데이터 준비 → 데이터 분석 → 시스템 구현 → 평가 및 전개**

- 3계층: **단계(Phase) → 태스크(Task) → 스텝(Step)**
- 각 단계 세부 내용
  | 단계 | 주요 태스크 |
  |---|---|
  | 분석 기획 | 비즈니스 이해 및 범위 설정, 프로젝트 정의·수행계획, **프로젝트 위험계획 수립** |
  | 데이터 준비 | 필요 데이터 정의, 데이터 스토어 설계, 데이터 수집·정합성 점검 |
  | 데이터 분석 | 분석용 데이터 준비, 텍스트 분석, 탐색적 분석(EDA), 모델링, 모델 평가·검증 |
  | 시스템 구현 | 설계 및 구현, 시스템 테스트 및 운영 |
  | 평가 및 전개 | 모델 발전 계획 수립, 프로젝트 성과 평가·보고 |

- **위험 대응 방법 4가지**: 회피(Avoid), 전이(Transfer), 완화(Mitigate), 수용(Accept)

## 3장. 분석 과제 발굴

### 3-1. 하향식 접근법 (Top-Down) ⭐
문제가 **주어진** 상황에서 해법을 찾는 방식
**문제 탐색 → 문제 정의 → 해결 방안 탐색 → 타당성 검토**

- **문제 탐색 도구 — 비즈니스 모델 캔버스** 5영역: **업무, 제품, 고객, 규제와 감사, 지원 인프라**
- **분석 기회 발굴 범위 확장** (관점 넓히기)
  - 거시적 관점 **STEEP**: 사회(Social), 기술(Technological), 경제(Economic), 환경(Environmental), 정치(Political)
  - 경쟁자 확대 관점: 대체재, 경쟁자, 신규 진입자
  - 시장 니즈 변화 관점: 고객, 채널, 영향자
  - 역량의 재해석 관점: 내부 역량, 파트너 네트워크
- **타당성 검토**: 경제적 타당성(비용 대비 효과), 데이터 및 기술적 타당성

### 3-2. 상향식 접근법 (Bottom-Up) ⭐
문제가 **정의되지 않은** 상황에서 **데이터부터 보며** 문제를 찾는 방식
- **디자인 사고**(Design Thinking): 발산(Diverge) ↔ 수렴(Converge) 반복
- **비지도 학습** 활용 (정답 없이 데이터 자체의 패턴 탐색)
- **프로토타이핑 접근**: 일단 분석해 보고 결과를 보며 개선 (시행착오)
- "Why(왜)" 보다 **"What(무엇)"** 관점

### 3-3. 분석 프로젝트 관리 — 5가지 속성 ⭐
**Data Size, Data Complexity, Speed, Analytic Complexity, Accuracy & Precision**

- **Accuracy(정확도)** vs **Precision(정밀도)**: 트레이드오프 관계인 경우가 많음
  - Accuracy: 모델과 실제 값의 차이가 적음 (과녁 중심 근처)
  - Precision: 여러 번 반복해도 결과가 일관됨 (탄착군이 모여 있음)
- **Analytic Complexity**: 정확도와 **해석 가능성** 사이의 균형점을 찾아야 함

### 3-4. 분석 과제 관리 10가지 영역 (ISO 21500 기반)
통합, 이해관계자, 범위, 자원, 시간, 원가, 리스크, 품질, 조달, 의사소통

### 4-1. 우선순위 고려 요소
- **전략적 중요도**, **비즈니스 성과/ROI**, **실행 용이성**

### 4-2. ROI 관점의 빅데이터 4V

|---|---|
| Volume, Variety, Velocity | **Value** |

### 4-3. 포트폴리오 사분면 분석 ⭐⭐ (매우 자주 출제)
가로축 = **시급성**(현재/미래), 세로축 = **난이도**(어려움/쉬움)

| | 시급성: 현재 (Current) | 시급성: 미래 (Future) |
|---|---|---|
| 난이도: **어려움** | **1사분면** | **2사분면** |
| 난이도: **쉬움** | **3사분면** | **4사분면** |

- **가장 먼저** 할 과제: **3사분면** (급하고 쉬움) / **가장 나중**: **2사분면** (안 급하고 어려움)
- **시급성**을 우선 기준으로 → **3 → 4 → 2**
- **난이도**를 우선 기준으로 → **3 → 1 → 2**

## 5장. 분석 거버넌스 체계

### 5-1. 거버넌스 구성요소 5가지
**조직(Organization), 과제 기획/운영 프로세스(Process), 분석 관련 시스템(System), 데이터(Data), 분석 관련 교육 및 마인드 육성 체계(Human Resource)**

### 5-2. 분석 준비도 (Readiness) — 6가지 영역 ⭐
**분석 업무 파악, 인력 및 조직, 분석 기법, 분석 데이터, 분석 문화, IT 인프라**

### 5-3. 분석 성숙도 (Maturity) ⭐
CMMI 모델 기반, 단계: **도입 → 활용 → 확산 → 최적화**
평가 부문: **비즈니스 부문, 조직·역량 부문, IT 부문**

### 5-4. 준비도 × 성숙도 사분면 ⭐⭐
| | 준비도 **낮음** | 준비도 **높음** |
|---|---|---|
| 성숙도 **높음** | **정착형** | **확산형** |
| 성숙도 **낮음** | **준비형** | **도입형** |

> 💡 외우는 법: 둘 다 낮으면 이제 **준비**, 둘 다 높으면 **확산**. 준비도만 높으면 바로 **도입** 가능, 성숙도만 높으면 **정착**이 필요.

### 5-5. 분석 조직 구조 3가지 ⭐
| 구조 | 특징 |
|---|---|
| **집중형** | 별도 분석 전담 조직이 전사 분석 수행. 현업 부서와 **업무 중복·이원화** 가능성 |
| **기능 중심형** | 각 현업 부서가 **직접** 분석. 전사적 관점 분석이 어려움, 일반적인 형태 |
| **분산형** | 분석 전문 인력을 **현업 부서에 배치**. 전사 차원 우선순위 + 신속한 실무 적용 (가장 이상적) |

### 5-6. 데이터 거버넌스 ⭐
- 구성 요소 3가지: **원칙(Principle), 조직(Organization), 프로세스(Process)**
- 체계: **데이터 표준화 → 데이터 관리 체계 → 데이터 저장소 관리 → 표준화 활동**
  - 데이터 표준화: 표준 용어 설정, 명명 규칙, **메타데이터** 구축, **데이터 사전** 구축
- 빅데이터 거버넌스 추가 고려: **ILM(데이터 생명 주기 관리)**, 전담 조직(데이터 관리자 = Data Steward)

### 5-7. 분석 과제 관리 프로세스
- **과제 발굴**: 분석 아이디어 발굴 → 과제 후보 제안 → 분석 과제 확정
- **과제 수행**: 팀 구성 → 분석 과제 실행 → 분석 과제 진행 관리 → 결과 공유/개선

## 1장. R 기초와 데이터 마트

### 1-1. R 기본 문법 (시험에 나오는 수준만)
```r
x <- c(1, 2, 3)      # c(): 값을 묶어 "벡터"(한 줄짜리 데이터) 만들기, <- 는 "저장"
x * 2                # 2 4 6  (벡터는 원소마다 계산됨)
x[2]                 # 2      (R은 번호가 1부터 시작! 파이썬은 0부터)

head(df); str(df); summary(df)  # 앞부분 보기 / 구조 보기 / 요약 통계
```
- 자료형: 숫자형(numeric), 문자형(character), 논리형(TRUE/FALSE), 범주형(**factor**)

### 1-2. 결측값 처리 ⭐
| 방법 | 설명 |
|---|---|
| **완전 분석법** (삭제) | 결측이 있는 행을 통째로 삭제 — 간단하지만 데이터 손실 |
| **평균 대치법** | 평균으로 채움 — 간단하지만 분산이 작아지는 문제 |
| **단순 확률 대치법** | 확률적으로 뽑은 값으로 채움 (**Hot-deck**, Nearest Neighbor 등) |
| **다중 대치법** | 여러 번 대치 → 분석 → 결합 (**대치 → 분석 → 결합** 3단계) |

### 1-3. 이상값(Outlier) 판단 ⭐
- **ESD**: 평균 ± **3 × 표준편차** 밖이면 이상값
- **사분위수(상자그림)**: `Q1 − 1.5×IQR` 보다 작거나 `Q3 + 1.5×IQR` 보다 크면 이상값 (IQR = Q3 − Q1)
- 이상값이라고 무조건 삭제하지 않음! (예: 부정 사용 탐지에서는 이상값이 핵심)

## 2장. 통계 분석 기초

### 2-1. 표본 추출 방법 ⭐
| 방법 | 설명 | 비유 |
|---|---|---|
| **단순 랜덤 추출** | 모두 같은 확률로 무작위 | 제비뽑기 |
| **계통 추출** | 번호를 매겨 **일정 간격**마다 | 5번째마다 1명씩 |
| **층화 추출** | 집단(층)을 나눈 뒤 **각 층에서** 랜덤 | 학년별로 몇 명씩 |
| **군집 추출** | 집단(군집)을 나눈 뒤 **군집 자체**를 뽑아 전부 조사 | 몇 개 반을 통째로 |

> 💡 층화: 층 **내부는 비슷**, 층끼리는 다름 / 군집: 군집 **내부는 다양**, 군집끼리는 비슷

### 2-2. 척도 4가지 ⭐
| 척도 | 설명 | 예시 |
|---|---|---|
| **명목척도** | 이름·구분만 | 성별, 혈액형 |
| **순서척도** | 순서 있음 | 학년, 만족도(상/중/하) |
| **구간척도** | 간격 일정, **절대 0 없음** | 온도(℃), IQ |
| **비율척도** | 간격 일정 + **절대 0 있음** (곱셈·나눗셈 의미 있음) | 키, 몸무게, 나이 |

### 2-3. 기술통계 (데이터 요약)
- **중심**: 평균, **중앙값**(가운데 값, 이상값에 강함), 최빈값(가장 많이 나온 값)
- **퍼짐**: 분산, 표준편차(=√분산), 범위, IQR, **변동계수**(표준편차 ÷ 평균, 단위가 다른 자료 비교용)
- **모양** ⭐
  - **왜도**(좌우 치우침): 오른쪽 꼬리가 길면 왜도 > 0 → **최빈값 < 중앙값 < 평균**
    왼쪽 꼬리가 길면 왜도 < 0 → **평균 < 중앙값 < 최빈값**
  - **첨도**(뾰족함): 정규분포 기준보다 뾰족하면 첨도가 큼

### 2-4. 확률분포 ⭐
| 이산형 (셀 수 있음) | 연속형 (셀 수 없음) |
|---|---|
| **베르누이**: 성공/실패 1번 | **정규분포**: 종 모양, 평균 중심 대칭 |
| **이항분포**: 베르누이를 n번 → 성공 횟수 | **t분포**: 표본이 작을 때 평균 검정 (자유도↑ → 정규분포에 가까워짐) |
| **포아송분포**: 일정 시간/공간에서 사건 **발생 횟수** (예: 1시간 동안 걸려온 전화 수) | **카이제곱분포**: 분산·범주형 검정 |
| **기하분포**: 첫 성공까지 시도 횟수 | **F분포**: 두 분산의 비율 (분산분석, 회귀모형 검정) |
| | 균일분포, 지수분포(사건 간 대기 시간) |

- 기댓값 E(X): 평균이라 생각하면 됨. **E(aX+b) = aE(X)+b**, **Var(aX+b) = a²Var(X)** ⭐

### 2-5. 추정
- **점추정**: 모수를 하나의 값으로 추정 (예: 평균은 170)
- **구간추정**: 범위로 추정 (예: 95% 신뢰구간 165~175)
  - "95% 신뢰구간": 같은 방법으로 100번 구간을 만들면 약 95번은 참값을 포함한다는 뜻
  - 신뢰수준 ↑ → 구간 **넓어짐** / 표본 크기 ↑ → 구간 **좁아짐**

### 2-6. 가설 검정 ⭐⭐
- **귀무가설(H0)**: "차이가 없다, 효과가 없다" (기본 가정)
- **대립가설(H1)**: "차이가 있다" (내가 증명하고 싶은 것)
- **p-value**: 귀무가설이 맞다고 할 때, 지금 같은 결과가 나올 확률
  - **p-value < 유의수준(보통 0.05) → 귀무가설 기각** (차이가 있다!)
- **오류**
  | | H0가 **사실** | H0가 **거짓** |
  |---|---|---|
  | H0 **기각** | **제1종 오류 (α)** | 올바른 결정 (**검정력 = 1−β**) |
  | H0 **채택** | 올바른 결정 | **제2종 오류 (β)** |
  - 💡 제1종 오류 = "억울한 사람을 유죄로" (없는 효과를 있다고 함)

### 2-7. 검정 방법 고르기
| 상황 | 방법 |
|---|---|
| 한 집단 평균이 특정 값과 같은가? | **일표본 t검정** |
| 같은 사람의 전/후 비교 (다이어트 전후) | **대응표본 t검정** |
| 서로 다른 두 집단 평균 비교 (남 vs 여) | **독립표본 t검정** (먼저 등분산 검정) |
| 세 집단 이상 평균 비교 | **분산분석(ANOVA)** — F분포 사용 |
| 범주형 두 변수의 관련성 (성별 × 선호 브랜드) | **카이제곱 독립성 검정** |
| 관측 비율이 기대 비율과 맞는가? | **카이제곱 적합도 검정** |
| 정규성 검정 | **Shapiro-Wilk**, Kolmogorov-Smirnov, Q-Q plot |

- **비모수 검정** ⭐: 분포(정규성) 가정이 없을 때, **순위나 부호**를 사용
  - 부호 검정, 윌콕슨 부호순위 검정, 만-위트니 U 검정(윌콕슨 순위합), 크루스칼-왈리스 검정, 런 검정, 스피어만 순위상관

## 3장. 상관분석과 회귀분석 ⭐⭐

### 3-1. 상관분석
- **상관계수 r**: −1 ~ +1. 0에 가까우면 **선형** 관계 없음 (곡선 관계는 있을 수 있음!)
- **피어슨**: 연속형(등간·비율척도), 선형관계 / **스피어만**: 순서척도, 순위 기반(비모수)
- 상관관계 ≠ 인과관계

### 3-2. 회귀분석 기본
- 목적: X(독립변수, 원인)로 Y(종속변수, 결과)를 **예측하는 직선 식** 찾기 → `Y = β0 + β1·X + 오차`
- 계수 추정 방법: **최소제곱법(OLS)** — 잔차(실제값−예측값)의 **제곱합을 최소화**
- **회귀분석 가정 5가지** ⭐ : **선형성, 독립성, 등분산성, 비상관성, 정상성(정규성)**
  - 잔차 그래프가 특정 패턴 없이 고르게 흩어져 있어야 함
  - 정규성: Q-Q plot에서 점들이 직선 위에 있어야 함

### 3-3. R의 회귀분석 출력 읽기 ⭐⭐ (매회 나옴)
```
Coefficients:
            Estimate Std. Error t value Pr(>|t|)
(Intercept) -17.5791     6.7584  -2.601   0.0123 *
speed         3.9324     0.4155   9.464 1.49e-12 ***
---
Residual standard error: 15.38 on 48 degrees of freedom
Multiple R-squared:  0.6511,	Adjusted R-squared:  0.6438
F-statistic: 89.57 on 1 and 48 DF,  p-value: 1.49e-12
```
| 확인할 곳 | 해석 |
|---|---|
| `Estimate` | 회귀계수. speed가 1 늘면 dist가 **약 3.93 증가** |
| `Pr(>|t|)` | 각 **변수**가 유의한지 (t검정). 0.05보다 작으면 유의 |
| `Multiple R-squared` | **결정계수 R²**: 모형이 Y의 변동을 **65.1%** 설명 (0~1, 클수록 좋음) |
| `Adjusted R-squared` | 변수 개수를 고려한 R² (다중회귀에서 사용) |
| `F-statistic`의 p-value | **모형 전체**가 유의한지 (F검정) |
| `degrees of freedom` | 잔차 자유도 = n − (변수 개수) − 1 → 여기선 50−1−1 = 48 |

- 계산식: **R² = SSR / SST = 1 − SSE / SST** (SST=전체 변동, SSR=회귀로 설명된 변동, SSE=설명 못한 변동)

### 3-4. 다중회귀 주의점
- **다중공선성**: 독립변수끼리 강하게 상관 → 계수가 불안정. **VIF > 10** 이면 심각 → 변수 제거, 주성분분석, 릿지 등
- **변수 선택법** ⭐
  - **전진 선택법**: 변수 없음에서 시작 → 하나씩 **추가**
  - **후진 제거법**: 전부 넣고 시작 → 하나씩 **제거**
  - **단계적 선택법**: 추가·제거 반복
  - 기준: **AIC, BIC** (작을수록 좋은 모형), BIC는 변수 많을 때 벌점이 더 큼
- **정규화(규제) 회귀** ⭐
  - **릿지(Ridge)**: **L2** 규제(계수 제곱합), 계수를 0에 가깝게 줄임 (0은 안 됨)
  - **라쏘(Lasso)**: **L1** 규제(계수 절댓값 합), 계수를 **정확히 0**으로 → 변수 선택 효과
  - **엘라스틱넷**: L1 + L2 혼합

### 3-5. 로지스틱 회귀 (분류용 회귀) ⭐
- Y가 **범주형(예/아니오)** 일 때 사용. 결과는 **0~1 사이 확률**
- **오즈(Odds)** = 성공확률 / 실패확률 = p / (1−p)
- 로짓 변환: log(오즈) = β0 + β1·X
- 해석: X가 1 증가하면 오즈가 **exp(β1) 배** 증가 ⭐
- R: `glm(y ~ x, family = binomial)`

## 4장. 시계열 분석과 다변량 분석

### 4-1. 시계열 ⭐
- **정상성**(stationarity) 조건: ① 평균이 일정 ② 분산이 시점에 무관 ③ 공분산이 시차에만 의존
  - 평균이 일정하지 않으면 → **차분**(바로 앞 값과의 차이) / 분산이 일정하지 않으면 → **변환**(로그 등)
- **모형**
  - **AR(p)** 자기회귀: 과거 **자기 값**으로 예측 → **PACF**가 p 이후 절단
  - **MA(q)** 이동평균: 과거 **오차**로 예측 → **ACF**가 q 이후 절단
  - **ARIMA(p, d, q)**: d = 차분 횟수. 예) ARIMA(0,1,1) → 1번 차분하면 MA(1)
- **분해 시계열** 요인 4가지: **추세, 계절, 순환, 불규칙**

### 4-2. 차원 축소
- **주성분 분석(PCA)** ⭐: 상관 있는 여러 변수를 **서로 상관없는 소수의 주성분**으로 요약
  - 주성분 개수 선택: **누적 기여율 70~90%** 또는 **Scree plot의 꺾이는 지점(elbow)** 직전
  - R 출력의 `Cumulative Proportion` 행을 보고 판단
- **다차원 척도법(MDS)**: 개체들 사이 거리(비유사성)를 2~3차원 지도에 표현. 적합도는 **Stress** 값(0에 가까울수록 좋음)

## 5장. 정형 데이터 마이닝 ⭐⭐

### 5-1. 데이터 분할과 과대적합
- **과대적합(Overfitting)**: 학습 데이터는 너무 잘 맞히는데 새 데이터는 못 맞힘 (문제집 답만 외운 상태)
- 분할 방법
  - **홀드아웃**: 학습/검증/테스트로 나눔 (예: 7:3)
  - **K-fold 교차검증**: K개로 나눠 K번 반복, 매번 1개를 검증용
  - **붓스트랩**: **복원추출**. 한 번도 뽑히지 않을 확률 ≈ **36.8%** (OOB 데이터)

### 5-2. 분류 모델 평가 — 혼동행렬 ⭐⭐ (계산 문제 필수)
| | 예측 Positive | 예측 Negative |
|---|---|---|
| **실제 Positive** | TP (맞게 양성) | FN (놓침) |
| **실제 Negative** | FP (잘못 경보) | TN (맞게 음성) |

| 지표 | 공식 | 의미 |
|---|---|---|
| **정확도** (Accuracy) | (TP+TN) / 전체 | 전체 중 맞힌 비율 |
| **정밀도** (Precision) | TP / (TP+FP) | **양성이라 예측**한 것 중 진짜 양성 |
| **재현율 = 민감도** (Recall, Sensitivity, TPR) | TP / (TP+FN) | **실제 양성** 중 맞힌 비율 |
| **특이도** (Specificity) | TN / (TN+FP) | **실제 음성** 중 맞힌 비율 |
| **FPR** | FP / (TN+FP) = 1 − 특이도 | |
| **F1 score** | 2 × 정밀도 × 재현율 / (정밀도 + 재현율) | 정밀도·재현율 조화평균 |

- **ROC 곡선**: x축 = **FPR(1−특이도)**, y축 = **TPR(민감도)**. 왼쪽 위로 붙을수록 좋음
- **AUC**: ROC 아래 면적. 1에 가까울수록 좋고, 0.5면 동전 던지기 수준
- **이익도표(Gain chart) / 향상도 곡선(Lift curve)**: 상위 등급일수록 반응률이 높은지 확인

### 5-3. 의사결정나무 ⭐
- 질문을 거듭하며 나무 모양으로 분류/예측 (스무고개). **해석이 쉬움**이 최대 장점
- **분리 기준**
  | 목표변수 | 기준 |
  |---|---|
  | **이산형(분류나무)** | **카이제곱 통계량의 p값**, **지니 지수**, **엔트로피 지수** (불순도가 작아지는 쪽으로) |
  | **연속형(회귀나무)** | **F 통계량의 p값**, **분산 감소량** |
- **알고리즘**: CART(지니 지수 / 분산 감소, **이진 분리**), C4.5·C5.0(엔트로피), CHAID(카이제곱 / F통계량)
- **정지 규칙**: 더 이상 분리하지 않는 조건 / **가지치기(Pruning)**: 과대적합 방지를 위해 가지를 잘라냄
- 지니 지수 = 1 − Σ(pᵢ²) ⭐ 예) 빨강 5개, 파랑 5개 → 1 − (0.5² + 0.5²) = **0.5**

### 5-4. 앙상블 ⭐
여러 모델의 예측을 합쳐 성능 향상
- **배깅(Bagging)**: 붓스트랩 표본 여러 개 → 각각 모델 → **투표/평균**. 분산 감소
- **부스팅(Boosting)**: 순차적으로, 이전 모델이 **틀린 데이터에 가중치**를 더 줌 (AdaBoost, GBM, XGBoost, LightGBM)
- **랜덤 포레스트**: 배깅 + 나무마다 **변수도 랜덤하게 선택** → 상관 줄여 성능 향상

### 5-5. 인공신경망
- 입력층 → 은닉층 → 출력층, 가중치를 **역전파(Backpropagation)** 로 학습
- **활성화 함수**: 계단(step), **시그모이드**(0~1, 이진분류 출력), **소프트맥스**(다중분류 출력, 확률 합 1), tanh(−1~1), **ReLU**(음수→0, 은닉층에 주로 사용)
- **기울기 소실 문제**: 층이 깊을 때 시그모이드 사용 시 발생 → ReLU로 완화
- 단점: 결과 **해석이 어려움**(블랙박스)

### 5-6. 기타 분류 모델
- **SVM**: 두 집단 사이 **마진(여백)을 최대화**하는 경계선
- **나이브 베이즈**: 베이즈 정리 + 변수들이 서로 **독립**이라고 가정
- **K-NN**: 가장 가까운 K개 이웃의 다수결 (학습 과정이 거의 없음 = 게으른 학습)

### 5-7. 군집 분석 (정답 없는 비지도 학습) ⭐
- **거리 측도**
  - 연속형: **유클리드**(직선거리), **맨해튼**(격자 길 따라), 민코프스키, **표준화 거리**, **마할라노비스**(변수 간 상관까지 고려)
  - 범주형: **자카드** 거리/계수
- **계층적 군집**: 가까운 것끼리 차례로 묶음 → 결과를 **덴드로그램**(나무 그림)으로 표현
  - 연결법: **최단연결**(가장 가까운 점), **최장연결**(가장 먼 점), **평균연결**, **중심연결**, **와드연결**(군집 내 오차제곱합 증가량 최소)
- **K-평균(K-means)** ⭐: K(군집 수)를 **미리 정함** → 중심 배정 → 재계산 반복
  - 단점: **이상값에 민감**, 초깃값에 따라 결과가 다름, 볼록한 모양 군집만 잘 찾음
  - K 정하기: 엘보우 방법, **실루엣 계수**(1에 가까울수록 군집 잘 나뉨)
- **DBSCAN**: 밀도 기반, 임의 모양 군집 가능, 이상값에 강함
- **혼합분포 군집**: 여러 확률분포의 혼합으로 보고 **EM 알고리즘**으로 추정
- **SOM (자기조직화지도)**: 인공신경망 기반, 고차원 데이터를 2차원 격자로 표현. **역전파 사용 X**

### 5-8. 연관 분석 (장바구니 분석) ⭐⭐ (계산 문제 필수)
규칙 "A를 사면 B도 산다" (A → B) 를 평가하는 3가지 지표

| 지표 | 공식 | 의미 |
|---|---|---|
| **지지도** (Support) | P(A∩B) = A와 B 동시 포함 거래 수 / 전체 거래 수 | 얼마나 **자주** 같이 나오나 |
| **신뢰도** (Confidence) | P(A∩B) / P(A) | A를 산 사람 중 B도 산 비율 |
| **향상도** (Lift) | 신뢰도 / P(B) = P(A∩B) / (P(A)·P(B)) | **1이면 독립**, **1보다 크면 양의 관계**, 1보다 작으면 음의 관계 |

**예제**: 거래 10건, 빵 6건, 우유 4건, 빵·우유 동시 3건일 때 규칙 "빵 → 우유"
- 지지도 = 3/10 = **0.3**
- 신뢰도 = 3/6 = **0.5**
- 향상도 = 0.5 / (4/10) = **1.25** → 빵을 사면 우유를 살 확률이 1.25배 (양의 관계)

- 알고리즘: **Apriori**(최소 지지도 이상인 빈발 항목만 조합해 계산량 감소), **FP-Growth**(트리 구조, Apriori보다 빠름)
- 장점: 결과가 이해하기 쉬움 / 단점: 품목이 많으면 계산량 폭증, 거래가 적은 품목은 규칙 발견이 어려움
- **순차 패턴**: 연관 분석 + **시간 순서** 고려

### 5-9. 비정형 데이터 (간단히)
- **텍스트 마이닝**: 말뭉치(Corpus), 불용어 제거, 어간 추출(Stemming), **TDM**(단어-문서 행렬), 워드클라우드
- **사회연결망 분석(SNA) 중심성** ⭐
  - **연결 정도 중심성**: 직접 연결된 수
  - **근접 중심성**: 다른 모든 노드까지 거리가 짧은 정도
  - **매개 중심성**: 다른 노드들 사이 **다리 역할**을 하는 정도
  - **위세 중심성**: 영향력 있는 사람과 연결될수록 높음 (예: 구글 PageRank)
