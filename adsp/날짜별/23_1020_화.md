<sub>📘 3과목</sub>

### 5-2. 분류 모델 평가 — 혼동행렬 ⭐⭐ (계산 문제 필수)
| | 예측 Positive | 예측 Negative |
|---|---|---|
| **실제 Positive** | TP (맞게 양성) | FN (놓침) |
| **실제 Negative** | FP (잘못 경보) | TN (맞게 음성) |

| 지표 | 공식 | 의미 |
|---|---|---|
| **정확도** (Accuracy) | (TP+TN) / 전체 | 전체 중 맞힌 비율 |
| **정밀도** (Precision) | TP / (TP+FP) | **양성이라 예측**한 것 중 진짜 양성 |
| **재현율 = 민감도** (Recall, Sensitivity, TPR) | TP / (TP+FN) | **실제 양성** 중 맞힌 비율 |
| **특이도** (Specificity) | TN / (TN+FP) | **실제 음성** 중 맞힌 비율 |
| **FPR** | FP / (TN+FP) = 1 − 특이도 | |
| **F1 score** | 2 × 정밀도 × 재현율 / (정밀도 + 재현율) | 정밀도·재현율 조화평균 |

- **ROC 곡선**: x축 = **FPR(1−특이도)**, y축 = **TPR(민감도)**. 왼쪽 위로 붙을수록 좋음
- **AUC**: ROC 아래 면적. 1에 가까울수록 좋고, 0.5면 동전 던지기 수준
- **이익도표(Gain chart) / 향상도 곡선(Lift curve)**: 상위 등급일수록 반응률이 높은지 확인

## ✅ 확인 문제

**23.** 다음 혼동행렬에서 **재현율(Recall)** 과 **특이도**는?

| | 예측 양성 | 예측 음성 |
|---|---|---|
| 실제 양성 | 40 | 10 |
| 실제 음성 | 20 | 30 |

① 0.8 / 0.6 ② 0.67 / 0.6 ③ 0.8 / 0.75 ④ 0.7 / 0.6

<details><summary>▶ 정답 보기</summary>

**①** — TP=40, FN=10, FP=20, TN=30
- 재현율 = TP/(TP+FN) = 40/50 = **0.8**
- 특이도 = TN/(TN+FP) = 30/50 = **0.6**
- (참고) 정확도 = 70/100 = 0.7, 정밀도 = 40/60 ≈ 0.67, F1 ≈ 0.727
</details>

**26.** ROC 곡선의 x축과 y축은?
① x: 민감도, y: 특이도 ② x: 1−특이도, y: 민감도 ③ x: 정밀도, y: 재현율 ④ x: 특이도, y: 정확도

<details><summary>▶ 정답 보기</summary>

**②** — x축 = FPR(1−특이도), y축 = TPR(민감도)
</details>

## ✏️ 스스로 체크 (안 보고 말할 수 있으면 체크)

- [ ] 정밀도 = TP / (TP + FP)
- [ ] 재현율(민감도) = TP / (TP + FN)
- [ ] 특이도 = TN / (TN + FP)
- [ ] ROC: x축 1 − 특이도, y축 민감도
