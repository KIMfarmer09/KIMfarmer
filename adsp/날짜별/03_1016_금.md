### 3-1. 데이터 사이언스
- 데이터로부터 의미 있는 정보를 추출하는 학문. 통계학보다 넓은 개념(정형 + 비정형 데이터 모두).
- 구성 요소: **Analytics**(분석) + **IT**(데이터 처리) + **비즈니스 분석**

### 3-2. 데이터 사이언티스트의 역량 ⭐
| Hard Skill | Soft Skill |
|---|---|
| 빅데이터에 대한 이론적 지식 | **통찰력 있는 분석** (창의적 사고, 호기심) |
| 분석 기술에 대한 숙련 | **설득력 있는 전달** (스토리텔링, 시각화) |
| | **다분야 간 협력** (커뮤니케이션) |

> 💡 함정: "시각화"는 Soft Skill(설득력 있는 전달)에 속합니다.

### 3-3. 개인정보 비식별화 기법 ⭐
| 기법 | 예시 |
|---|---|
| **가명 처리** | 홍길동 → 임꺽정 |
| **총계 처리** | 개인 키 대신 "평균 키 170cm" |
| **데이터 삭제** | 주민번호 뒷자리 삭제 |
| **데이터 범주화** | 나이 27세 → 20대 |
| **데이터 마스킹** | 홍길동 → 홍○○ |

### 3-4. 데이터 3법 (2020년 개정)
- **개인정보 보호법, 정보통신망법, 신용정보법**
- 핵심: **가명정보** 개념 도입 → 동의 없이도 통계·연구·공익적 기록 보존 목적으로 활용 가능

### 3-5. 전략 인사이트
- 단순히 분석을 잘하는 것보다 **비즈니스 핵심 가치에 집중**하는 것이 중요
- 일차적인 분석(부서 단위 업무 개선)에서 → **전략적 통찰**(전사 경쟁력)로 나아가야 함
- 빅데이터 회의론의 원인: 과거 CRM 실패 경험, 성과 없는 투자 → "데이터 양보다 **분석적 사고**가 중요"

### 보-1. 1과목 보충 ⭐

**빅데이터 출현 배경**
| 관점 | 내용 |
|---|---|
| 산업계 | 고객 데이터가 쌓이면서 **양이 질로 전환** (데이터에서 가치를 찾기 시작) |
| 학계 | 게놈·천문학처럼 **거대 데이터를 다루는 학문** 확산 |
| 기술 발전 | 디지털화, 저장 기술 발전·가격 하락, 인터넷·모바일 보급, **클라우드 컴퓨팅** |

**빅데이터 비유** ⭐
- **산업혁명의 석탄·철**: 모든 산업의 생산성을 높임
- **21세기의 원유**: 새로운 가치를 만드는 연료
- **렌즈**: 현미경처럼 세상을 새로 보게 함 (예: 구글 Ngram Viewer)
- **플랫폼**: 여러 서비스가 공동으로 활용하는 기반 (예: 페이스북 API)

**미래 빅데이터의 3요소** ⭐
| 요소 | 변화 |
|---|---|
| 데이터 | 모든 것의 **데이터화** (Datafication) |
| 기술 | 진화하는 **알고리즘**, 인공지능 |
| 인력 | **데이터 사이언티스트**, **알고리즈미스트** |

**데이터 크기 단위** (1,024배씩 커짐)
**KB < MB < GB < TB < PB < EB < ZB < YB**
> 💡 외우는 법: "킬 메 기 테 페 엑 제 요"

**DB 관련 용어**
- **메타데이터**: 데이터에 **관한** 데이터 (예: 사진의 촬영 날짜·위치)
- **인덱스**: 빨리 찾기 위한 **색인** (책 뒤의 찾아보기)
- **DB 설계 순서**: 요구 조건 분석 → 개념적 설계 → 논리적 설계 → 물리적 설계

**SQL 명령어 종류**
| 종류 | 뜻 | 명령어 |
|---|---|---|
| **DDL** (정의어) | 표의 **구조**를 만들고 바꿈 | CREATE, ALTER, DROP |
| **DML** (조작어) | 표 안의 **데이터**를 다룸 | SELECT, INSERT, UPDATE, DELETE |
| **DCL** (제어어) | **권한** 관리 | GRANT, REVOKE |

**개인정보 3단계** ⭐
| 구분 | 설명 | 활용 |
|---|---|---|
| 개인정보 | 특정 개인을 알아볼 수 있음 | 동의 필요 |
| **가명정보** | 추가 정보 없이는 개인을 알아볼 수 없음 | 통계·연구·공익 목적이면 **동의 없이** 가능 |
| **익명정보** | 어떤 방법으로도 개인을 알아볼 수 없음 | **개인정보 보호법 적용 제외** (자유롭게 활용) |

**가트너가 제시한 데이터 사이언티스트 역량**: 데이터 관리, 분석 모델링, 비즈니스 분석, 소프트 스킬
