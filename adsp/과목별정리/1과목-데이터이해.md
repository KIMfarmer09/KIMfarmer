## 1장. 데이터의 이해

### 1-1. 데이터의 유형
| 구분 | 설명 | 예시 |
|---|---|---|
| **정량적 데이터** | 숫자로 표현, 저장·분석이 쉬움 | 키, 온도, 매출액 |
| **정성적 데이터** | 말·글·그림 등 형태가 정해지지 않음, 분석이 어려움 | 설문 주관식 답변, SNS 글 |

### 1-2. 암묵지 vs 형식지 ⭐
- **암묵지**: 머릿속에 있어서 겉으로 드러나지 않는 지식 (예: 장인의 손맛, 김장 노하우)
- **형식지**: 문서·매뉴얼처럼 겉으로 드러나 공유 가능한 지식

**지식 전환 4단계 (SECI 모델, 노나카)** — 순서대로 외우기: **공 → 표 → 연 → 내**

| 단계 | 방향 | 뜻 |
|---|---|---|
| **공통화** (Socialization) | 암묵지 → 암묵지 | 같이 일하며 보고 배움 |
| **표출화** (Externalization) | 암묵지 → 형식지 | 노하우를 문서로 작성 |
| **연결화** (Combination) | 형식지 → 형식지 | 문서끼리 합쳐 새 문서 |
| **내면화** (Internalization) | 형식지 → 암묵지 | 문서를 읽고 내 것으로 체득 |

### 1-3. DIKW 피라미드 ⭐
아래에서 위로 갈수록 가치가 높아집니다.

| 단계 | 뜻 | 예시 |
|---|---|---|
| **D**ata (데이터) | 가공 전의 객관적 사실 | A마트 볼펜 100원, B마트 200원 |
| **I**nformation (정보) | 데이터를 가공해 **의미**를 도출 | A마트 볼펜이 더 싸다 |
| **K**nowledge (지식) | 정보를 구조화해 **내 행동**에 연결 | 가격이 싼 A마트에서 사야겠다 |
| **W**isdom (지혜) | 지식을 바탕으로 한 **창의적 아이디어** | A마트의 다른 물건도 쌀 것이다 |

### 1-4. 데이터베이스(DB)의 정의와 특징
- **정의**: 체계적으로 수집·축적하여 다양한 용도와 방법으로 이용할 수 있게 정리한 정보의 집합체
- **특징 4가지** ⭐ (통·저·공·변):
  - **통합된** 데이터 (중복 없음), **저장된** 데이터 (컴퓨터 저장매체), **공용** 데이터 (여럿이 함께 사용), **변화되는** 데이터 (계속 갱신)
- **DBMS**: DB를 관리하는 프로그램 (예: Oracle, MySQL) / **SQL**: DB에 질문(조회)하는 언어

### 1-5. 기업 내부 데이터베이스 ⭐
| 용어 | 한 줄 설명 |
|---|---|
| **OLTP** | 실시간 거래 처리 (예: 은행 입출금) — "기록" 중심 |
| **OLAP** | 다차원 분석 처리 — "분석" 중심 |
| **ERP** | 인사·재무·생산 등 **전사 자원**을 통합 관리 |
| **CRM** | **고객** 관계 관리 |
| **SCM** | **공급망**(원재료→생산→유통) 관리 |
| **BI** | 데이터를 리포트·대시보드로 보여줘 의사결정 지원 |
| **KMS** | 지식 관리 시스템 |
| **DW (데이터 웨어하우스)** | 분석용으로 모아둔 대형 창고 |
| **데이터 마트** | DW의 일부, 특정 부서용 작은 창고 |

**DW의 특징 4가지** ⭐: **주제 지향적**, **통합적**, **시계열성**, **비휘발성**(한 번 적재되면 잘 안 바뀜)

## 2장. 데이터의 가치와 미래

### 2-1. 빅데이터 정의 — 3V ⭐
- **Volume**(규모), **Variety**(다양성), **Velocity**(속도)
- 추가: **Value**(가치), **Veracity**(정확성) → 5V

### 2-2. 빅데이터가 만든 변화 ⭐ (자주 나옴!)
| 과거 | → | 현재 |
|---|---|---|
| 사전 처리 | → | **사후 처리** (일단 모으고 나중에 분석) |
| 표본 조사 | → | **전수 조사** |
| 질(Quality) | → | **양(Quantity)** |
| 인과관계 | → | **상관관계** |

### 2-3. 빅데이터의 가치 산정이 어려운 이유 ⭐
1. **데이터 활용 방식**: 재사용·재조합·다목적 활용 → 누가 어디에 쓸지 모름
2. **새로운 가치 창출**: 기존에 없던 가치를 만듦
3. **분석 기술의 발전**: 지금은 가치 없는 데이터도 나중에 가치가 생김

### 2-4. 빅데이터 활용 기본 테크닉 ⭐ (사례 ↔ 기법 연결 문제)
| 기법 | 사례 키워드 |
|---|---|
| **연관규칙 학습** | "커피 사는 사람이 탄산음료도 많이 사는가?" |
| **유형 분석(분류)** | "이 사용자는 어느 그룹에 속하는가?" |
| **유전 알고리즘** | "최적의 택배 차량 배치", 진화·최적화 |
| **기계 학습** | "시청 기록으로 영화 추천" |
| **회귀 분석** | "나이가 구매 차량 종류에 영향을 주는가?" |
| **감정 분석** | "새 제품에 대한 고객 평가는 긍정?부정?" |
| **소셜 네트워크 분석** | "고객 간 관계망에서 영향력 있는 사람은?" |

### 2-5. 빅데이터 위기 요인과 통제 방안 ⭐
| 위기 요인 | 통제 방안 |
|---|---|
| **사생활 침해** | 개인정보 제공자의 "동의제" → 사용자의 **"책임제"** 로 |
| **책임 원칙 훼손** (예측만으로 처벌) | 결과 기반 책임 원칙 고수 |
| **데이터 오용** (잘못된 분석) | **알고리즈미스트**(알고리즘 해석·피해 구제 전문가) 도입 |

### 2-6. 데이터 가치 패러다임 변화
**Digitalization(디지털화) → Connection(연결) → Agency(에이전시: 연결을 효과적으로 관리)**

## 3장. 가치 창조를 위한 데이터 사이언스와 전략 인사이트

### 3-1. 데이터 사이언스
- 데이터로부터 의미 있는 정보를 추출하는 학문. 통계학보다 넓은 개념(정형 + 비정형 데이터 모두).
- 구성 요소: **Analytics**(분석) + **IT**(데이터 처리) + **비즈니스 분석**

### 3-2. 데이터 사이언티스트의 역량 ⭐
| Hard Skill | Soft Skill |
|---|---|
| 빅데이터에 대한 이론적 지식 | **통찰력 있는 분석** (창의적 사고, 호기심) |
| 분석 기술에 대한 숙련 | **설득력 있는 전달** (스토리텔링, 시각화) |
| | **다분야 간 협력** (커뮤니케이션) |

> 💡 함정: "시각화"는 Soft Skill(설득력 있는 전달)에 속합니다.

### 3-3. 개인정보 비식별화 기법 ⭐
| 기법 | 예시 |
|---|---|
| **가명 처리** | 홍길동 → 임꺽정 |
| **총계 처리** | 개인 키 대신 "평균 키 170cm" |
| **데이터 삭제** | 주민번호 뒷자리 삭제 |
| **데이터 범주화** | 나이 27세 → 20대 |
| **데이터 마스킹** | 홍길동 → 홍○○ |

### 3-4. 데이터 3법 (2020년 개정)
- **개인정보 보호법, 정보통신망법, 신용정보법**
- 핵심: **가명정보** 개념 도입 → 동의 없이도 통계·연구·공익적 기록 보존 목적으로 활용 가능

### 3-5. 전략 인사이트
- 단순히 분석을 잘하는 것보다 **비즈니스 핵심 가치에 집중**하는 것이 중요
- 일차적인 분석(부서 단위 업무 개선)에서 → **전략적 통찰**(전사 경쟁력)로 나아가야 함
- 빅데이터 회의론의 원인: 과거 CRM 실패 경험, 성과 없는 투자 → "데이터 양보다 **분석적 사고**가 중요"
