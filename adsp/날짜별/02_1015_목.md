## 📖 오늘 공부할 내용

<sub>📘 1과목</sub>

### 2-1. 빅데이터 정의 — 3V ⭐
- **Volume**(규모), **Variety**(다양성), **Velocity**(속도)
- 추가: **Value**(가치), **Veracity**(정확성) → 5V

### 2-2. 빅데이터가 만든 변화 ⭐ (자주 나옴!)
| 과거 | → | 현재 |
|---|---|---|
| 사전 처리 | → | **사후 처리** (일단 모으고 나중에 분석) |
| 표본 조사 | → | **전수 조사** |
| 질(Quality) | → | **양(Quantity)** |
| 인과관계 | → | **상관관계** |

### 2-3. 빅데이터의 가치 산정이 어려운 이유 ⭐
1. **데이터 활용 방식**: 재사용·재조합·다목적 활용 → 누가 어디에 쓸지 모름
2. **새로운 가치 창출**: 기존에 없던 가치를 만듦
3. **분석 기술의 발전**: 지금은 가치 없는 데이터도 나중에 가치가 생김

### 2-4. 빅데이터 활용 기본 테크닉 ⭐ (사례 ↔ 기법 연결 문제)
| 기법 | 사례 키워드 |
|---|---|
| **연관규칙 학습** | "커피 사는 사람이 탄산음료도 많이 사는가?" |
| **유형 분석(분류)** | "이 사용자는 어느 그룹에 속하는가?" |
| **유전 알고리즘** | "최적의 택배 차량 배치", 진화·최적화 |
| **기계 학습** | "시청 기록으로 영화 추천" |
| **회귀 분석** | "나이가 구매 차량 종류에 영향을 주는가?" |
| **감정 분석** | "새 제품에 대한 고객 평가는 긍정?부정?" |
| **소셜 네트워크 분석** | "고객 간 관계망에서 영향력 있는 사람은?" |

### 2-5. 빅데이터 위기 요인과 통제 방안 ⭐
| 위기 요인 | 통제 방안 |
|---|---|
| **사생활 침해** | 개인정보 제공자의 "동의제" → 사용자의 **"책임제"** 로 |
| **책임 원칙 훼손** (예측만으로 처벌) | 결과 기반 책임 원칙 고수 |
| **데이터 오용** (잘못된 분석) | **알고리즈미스트**(알고리즘 해석·피해 구제 전문가) 도입 |

### 2-6. 데이터 가치 패러다임 변화
**Digitalization(디지털화) → Connection(연결) → Agency(에이전시: 연결을 효과적으로 관리)**

**4.** 빅데이터가 만들어 낸 변화로 옳지 **않은** 것은?
① 사전처리 → 사후처리 ② 표본조사 → 전수조사 ③ 양 → 질 ④ 인과관계 → 상관관계

<details><summary>▶ 정답 보기</summary>

**③** — 반대입니다. **질 → 양**으로 변화했습니다.
</details>

**5.** "고객의 시청 기록을 바탕으로 좋아할 만한 영화를 추천"하는 데 가장 적절한 기법은?
① 유전 알고리즘 ② 기계 학습 ③ 회귀 분석 ④ 감정 분석

<details><summary>▶ 정답 보기</summary>

**② 기계 학습** — 과거 데이터로 학습해 예측·추천. 유전 알고리즘은 "최적화" 키워드.
</details>

**6.** 빅데이터 위기 요인 중 "데이터 오용"에 대한 통제 방안은?
① 동의제를 책임제로 전환 ② 결과 기반 책임 원칙 고수 ③ 알고리즈미스트 도입 ④ 데이터 3법 폐지

<details><summary>▶ 정답 보기</summary>

**③ 알고리즈미스트** — ①은 사생활 침해, ②는 책임 원칙 훼손에 대한 대책.
</details>
