### 2-6. 가설 검정 ⭐⭐
- **귀무가설(H0)**: "차이가 없다, 효과가 없다" (기본 가정)
- **대립가설(H1)**: "차이가 있다" (내가 증명하고 싶은 것)
- **p-value**: 귀무가설이 맞다고 할 때, 지금 같은 결과가 나올 확률
  - **p-value < 유의수준(보통 0.05) → 귀무가설 기각** (차이가 있다!)
- **오류**
  | | H0가 **사실** | H0가 **거짓** |
  |---|---|---|
  | H0 **기각** | **제1종 오류 (α)** | 올바른 결정 (**검정력 = 1−β**) |
  | H0 **채택** | 올바른 결정 | **제2종 오류 (β)** |
  - 💡 제1종 오류 = "억울한 사람을 유죄로" (없는 효과를 있다고 함)

### 2-7. 검정 방법 고르기
| 상황 | 방법 |
|---|---|
| 한 집단 평균이 특정 값과 같은가? | **일표본 t검정** |
| 같은 사람의 전/후 비교 (다이어트 전후) | **대응표본 t검정** |
| 서로 다른 두 집단 평균 비교 (남 vs 여) | **독립표본 t검정** (먼저 등분산 검정) |
| 세 집단 이상 평균 비교 | **분산분석(ANOVA)** — F분포 사용 |
| 범주형 두 변수의 관련성 (성별 × 선호 브랜드) | **카이제곱 독립성 검정** |
| 관측 비율이 기대 비율과 맞는가? | **카이제곱 적합도 검정** |
| 정규성 검정 | **Shapiro-Wilk**, Kolmogorov-Smirnov, Q-Q plot |

- **비모수 검정** ⭐: 분포(정규성) 가정이 없을 때, **순위나 부호**를 사용
  - 부호 검정, 윌콕슨 부호순위 검정, 만-위트니 U 검정(윌콕슨 순위합), 크루스칼-왈리스 검정, 런 검정, 스피어만 순위상관

### 보-7. R 검정 결과 읽기 ⭐⭐

**① t검정 출력**
```
	Welch Two Sample t-test

data:  mpg by am
t = -3.7671, df = 18.332, p-value = 0.001374
alternative hypothesis: true difference in means between group 0 and group 1 is not equal to 0
95 percent confidence interval:
 -11.280194  -3.209684
sample estimates:
mean in group 0 mean in group 1 
       17.14737        24.39231 
```
| 확인할 곳 | 해석 |
|---|---|
| `Welch` | **등분산을 가정하지 않은** t검정 (등분산 가정이면 "Two Sample t-test") |
| `p-value = 0.001374` | 0.05보다 작음 → **두 집단 평균이 다르다** |
| `95 percent confidence interval` | 평균 차이의 신뢰구간에 **0이 포함되지 않음** → 역시 유의 |
| `mean in group …` | 각 집단 평균 (group 1이 더 큼) |

**② 분산분석(ANOVA) 출력**
```
             Df Sum Sq Mean Sq F value Pr(>F)    
Species       2  63.21  31.606   119.3 <2e-16 ***
Residuals   147  38.96   0.265                   
```
| 확인할 곳 | 계산·해석 |
|---|---|
| Df (집단) | 집단 수 − 1 = 3 − 1 = **2** |
| Df (Residuals) | 전체 n − 집단 수 = 150 − 3 = **147** |
| Mean Sq | **Sum Sq ÷ Df** (63.21 ÷ 2 = 31.606) |
| F value | **집단 Mean Sq ÷ 잔차 Mean Sq** (31.606 ÷ 0.265 ≈ 119.3) |
| Pr(>F) | 0.05보다 작음 → 적어도 한 집단 평균은 다름 |
- 어느 집단끼리 다른지는 **사후검정**(Tukey HSD 등)으로 확인

**③ 카이제곱 검정**
- 출력: `X-squared = …, df = …, p-value = …`
- **자유도 = (행 개수 − 1) × (열 개수 − 1)** ⭐ — 예) 3×4 표 → 2 × 3 = **6**
- 기대빈도가 5 미만인 칸이 많으면 경고가 뜨고, 이때는 Fisher 정확 검정을 고려

**④ 정규성 검정 (shapiro.test)**
- 귀무가설 = "정규분포를 따른다" → **p-value > 0.05 이면 정규성 만족**

## ✏️ 스스로 체크 (안 보고 말할 수 있으면 체크)

- [ ] p-value < 0.05 → 귀무가설 **기각** / 제1종 오류(α) = 참인 H0를 기각
- [ ] 전/후 → 대응표본 t / 두 집단 → 독립표본 t / 세 집단 이상 → ANOVA
- [ ] ANOVA: 잔차 자유도 = n − 집단 수, F = 집단 MS ÷ 잔차 MS
- [ ] 카이제곱 자유도 = (행−1)(열−1) / Welch = 등분산 가정 X
