## 📖 오늘 공부할 내용

<sub>📘 2과목</sub>

### 2-1. 방법론 모델
- **폭포수 모델**: 단계를 순서대로, 이전 단계 완료 후 다음 단계 (하향식)
- **프로토타입 모델**: 일단 빠르게 만들어 보고 고객 피드백으로 개선 (상향식)
- **나선형 모델**: 반복하며 점진적 개발 (위험 관리에 유리, 복잡할 수 있음)

### 2-2. KDD 분석 방법론 (5단계) ⭐
**데이터셋 선택 → 데이터 전처리 → 데이터 변환 → 데이터 마이닝 → 결과 해석 및 평가**

> 💡 "잡음·이상치·결측치 처리"는 **전처리**, "차원 축소·변수 선택"은 **변환** 단계

### 2-3. CRISP-DM 방법론 (6단계) ⭐
**업무 이해 → 데이터 이해 → 데이터 준비 → 모델링 → 평가 → 전개**

- 4레벨 구조: **단계(Phase) → 일반화 태스크 → 세분화 태스크 → 프로세스 실행**
- 단계 간 **피드백(되돌아가기)** 이 가능
- 💡 "모델 과적합 문제 확인"은 **모델링** 단계, "모델이 업무 목적에 맞는지 평가"는 **평가** 단계

### 2-4. 빅데이터 분석 방법론 (5단계) ⭐
**분석 기획 → 데이터 준비 → 데이터 분석 → 시스템 구현 → 평가 및 전개**

- 3계층: **단계(Phase) → 태스크(Task) → 스텝(Step)**
- 각 단계 세부 내용
  | 단계 | 주요 태스크 |
  |---|---|
  | 분석 기획 | 비즈니스 이해 및 범위 설정, 프로젝트 정의·수행계획, **프로젝트 위험계획 수립** |
  | 데이터 준비 | 필요 데이터 정의, 데이터 스토어 설계, 데이터 수집·정합성 점검 |
  | 데이터 분석 | 분석용 데이터 준비, 텍스트 분석, 탐색적 분석(EDA), 모델링, 모델 평가·검증 |
  | 시스템 구현 | 설계 및 구현, 시스템 테스트 및 운영 |
  | 평가 및 전개 | 모델 발전 계획 수립, 프로젝트 성과 평가·보고 |

- **위험 대응 방법 4가지**: 회피(Avoid), 전이(Transfer), 완화(Mitigate), 수용(Accept)

① 업무 이해 → 데이터 이해 → 데이터 준비 → 모델링 → 평가 → 전개
② 데이터 이해 → 업무 이해 → 모델링 → 데이터 준비 → 평가 → 전개
③ 업무 이해 → 데이터 준비 → 데이터 이해 → 모델링 → 전개 → 평가
