### 4-3. 포트폴리오 사분면 분석 ⭐⭐ (매우 자주 출제)
가로축 = **시급성**(현재/미래), 세로축 = **난이도**(어려움/쉬움)

| | 시급성: 현재 (Current) | 시급성: 미래 (Future) |
|---|---|---|
| 난이도: **어려움** | **1사분면** | **2사분면** |
| 난이도: **쉬움** | **3사분면** | **4사분면** |

- **가장 먼저** 할 과제: **3사분면** (급하고 쉬움) / **가장 나중**: **2사분면** (안 급하고 어려움)
- **시급성**을 우선 기준으로 → **3 → 4 → 2**
- **난이도**를 우선 기준으로 → **3 → 1 → 2**

## ✅ 확인 문제

**13.** 포트폴리오 사분면 분석에서 **난이도**를 우선 기준으로 할 때 과제 수행 순서는?
① 3 → 4 → 2 ② 3 → 1 → 2 ③ 1 → 2 → 3 ④ 4 → 3 → 1

<details><summary>▶ 정답 보기</summary>

**② 3 → 1 → 2** — 쉬운 것(3, 4사분면) 중 급한 3 먼저, 그다음 급하지만 어려운 1, 마지막 2. 시급성 기준이면 3 → 4 → 2.
</details>
