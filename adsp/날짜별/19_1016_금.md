### 3-3. R의 회귀분석 출력 읽기 ⭐⭐ (매회 나옴)
```
Coefficients:
            Estimate Std. Error t value Pr(>|t|)
(Intercept) -17.5791     6.7584  -2.601   0.0123 *
speed         3.9324     0.4155   9.464 1.49e-12 ***
---
Residual standard error: 15.38 on 48 degrees of freedom
Multiple R-squared:  0.6511,	Adjusted R-squared:  0.6438
F-statistic: 89.57 on 1 and 48 DF,  p-value: 1.49e-12
```
| 확인할 곳 | 해석 |
|---|---|
| `Estimate` | 회귀계수. speed가 1 늘면 dist가 **약 3.93 증가** |
| `Pr(>|t|)` | 각 **변수**가 유의한지 (t검정). 0.05보다 작으면 유의 |
| `Multiple R-squared` | **결정계수 R²**: 모형이 Y의 변동을 **65.1%** 설명 (0~1, 클수록 좋음) |
| `Adjusted R-squared` | 변수 개수를 고려한 R² (다중회귀에서 사용) |
| `F-statistic`의 p-value | **모형 전체**가 유의한지 (F검정) |
| `degrees of freedom` | 잔차 자유도 = n − (변수 개수) − 1 → 여기선 50−1−1 = 48 |

- 계산식: **R² = SSR / SST = 1 − SSE / SST** (SST=전체 변동, SSR=회귀로 설명된 변동, SSE=설명 못한 변동)

## ✅ 확인 문제

**21.** 아래 R 회귀분석 결과에 대한 설명으로 옳지 **않은** 것은?
```
            Estimate Std. Error t value Pr(>|t|)
(Intercept) -17.5791     6.7584  -2.601   0.0123 *
speed         3.9324     0.4155   9.464 1.49e-12 ***
Multiple R-squared:  0.6511,	Adjusted R-squared:  0.6438
F-statistic: 89.57 on 1 and 48 DF,  p-value: 1.49e-12
```
① speed가 1 증가하면 종속변수는 약 3.93 증가한다.
② 모형은 종속변수 변동의 약 65%를 설명한다.
③ 유의수준 0.05에서 speed는 유의하지 않다.
④ 회귀모형은 유의수준 0.05에서 통계적으로 유의하다.

<details><summary>▶ 정답 보기</summary>

**③** — speed의 p-value = 1.49e-12 (0.00000000000149) < 0.05 → **유의하다**.
</details>
