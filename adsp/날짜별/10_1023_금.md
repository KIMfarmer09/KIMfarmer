### 3-4. 다중회귀 주의점
- **다중공선성**: 독립변수끼리 강하게 상관 → 계수가 불안정. **VIF > 10** 이면 심각 → 변수 제거, 주성분분석, 릿지 등
- **변수 선택법** ⭐
  - **전진 선택법**: 변수 없음에서 시작 → 하나씩 **추가**
  - **후진 제거법**: 전부 넣고 시작 → 하나씩 **제거**
  - **단계적 선택법**: 추가·제거 반복
  - 기준: **AIC, BIC** (작을수록 좋은 모형), BIC는 변수 많을 때 벌점이 더 큼
- **정규화(규제) 회귀** ⭐
  - **릿지(Ridge)**: **L2** 규제(계수 제곱합), 계수를 0에 가깝게 줄임 (0은 안 됨)
  - **라쏘(Lasso)**: **L1** 규제(계수 절댓값 합), 계수를 **정확히 0**으로 → 변수 선택 효과
  - **엘라스틱넷**: L1 + L2 혼합

### 3-5. 로지스틱 회귀 (분류용 회귀) ⭐
- Y가 **범주형(예/아니오)** 일 때 사용. 결과는 **0~1 사이 확률**
- **오즈(Odds)** = 성공확률 / 실패확률 = p / (1−p)
- 로짓 변환: log(오즈) = β0 + β1·X
- 해석: X가 1 증가하면 오즈가 **exp(β1) 배** 증가 ⭐
- R: `glm(y ~ x, family = binomial)`
