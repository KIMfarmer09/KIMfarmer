**7.** 데이터 사이언티스트의 Soft Skill에 해당하지 **않는** 것은?

**23.** 다음 혼동행렬에서 **재현율(Recall)** 과 **특이도**는?

| | 예측 양성 | 예측 음성 |
|---|---|---|
| 실제 양성 | 40 | 10 |
| 실제 음성 | 20 | 30 |

① 0.8 / 0.6 ② 0.67 / 0.6 ③ 0.8 / 0.75 ④ 0.7 / 0.6

<details><summary>▶ 정답 보기</summary>

**①** — TP=40, FN=10, FP=20, TN=30
- 재현율 = TP/(TP+FN) = 40/50 = **0.8**
- 특이도 = TN/(TN+FP) = 30/50 = **0.6**
- (참고) 정확도 = 70/100 = 0.7, 정밀도 = 40/60 ≈ 0.67, F1 ≈ 0.727
</details>

**24.** 거래 20건 중 A 포함 10건, B 포함 8건, A와 B 동시 포함 4건이다. 규칙 A → B의 **향상도**는?
① 0.4 ② 0.5 ③ 1.0 ④ 1.25

<details><summary>▶ 정답 보기</summary>

**③ 1.0**
- 지지도 = 4/20 = 0.2
- 신뢰도 = 4/10 = 0.4
- 향상도 = 신뢰도 / P(B) = 0.4 / (8/20) = 0.4 / 0.4 = **1.0** → A와 B는 **독립** (서로 관계 없음)
</details>
