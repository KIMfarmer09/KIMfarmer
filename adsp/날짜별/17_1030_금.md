### 1·2과목 최종 요약 (한 장)
- SECI: **공 → 표 → 연 → 내** / 표출화 = 암묵지 → 형식지
- DIKW: 데이터 → 정보(의미) → 지식(내 행동) → 지혜(창의)
- DB 특징: 통합·저장·공용·변화 / DW 특징: 주제 지향·통합·시계열·**비휘발**
- 빅데이터 변화: 사후처리 · 전수조사 · **양** · 상관관계
- 위기: 사생활 → 책임제 / 책임 원칙 훼손 → 결과 기반 책임 / 오용 → 알고리즈미스트
- Soft Skill: 통찰력 있는 분석 · 설득력 있는 전달(시각화) · 다분야 협력
- 분석 주제: 최적화(둘 다 앎) · 솔루션(대상만) · 통찰(방법만) · 발견(둘 다 모름)
- CRISP-DM: 업무 이해 → 데이터 이해 → 데이터 준비 → 모델링 → 평가 → 전개
- 빅데이터 방법론: 분석 기획 → 데이터 준비 → 데이터 분석 → 시스템 구현 → 평가·전개
- 하향식(문제 정의됨) vs 상향식(문제 불명확, 디자인 사고, 비지도 학습)
- 사분면: 시급성 기준 **3→4→2** / 난이도 기준 **3→1→2**
- 준비도·성숙도: 준비형(둘 다 낮음) · 확산형(둘 다 높음) · 도입형(준비도만 높음) · 정착형(성숙도만 높음)
- 조직: 집중형 · 기능 중심형 · **분산형**(현업 배치) / 데이터 거버넌스: 원칙·조직·프로세스

### 보-11. 시험 전날용 — 헷갈리는 쌍 20개 ⭐⭐⭐

| # | 헷갈리는 쌍 | 구분 포인트 |
|---|---|---|
| 1 | 표출화 vs 내면화 | 표출화 = 암묵 → **형식** / 내면화 = 형식 → **암묵** |
| 2 | OLTP vs OLAP | OLTP = 거래 **기록** / OLAP = 다차원 **분석** |
| 3 | DW vs 데이터 마트 | DW = 전사 창고 / 마트 = **부서용** 일부 |
| 4 | 솔루션 vs 통찰 | 솔루션 = **대상**만 앎 / 통찰 = **방법**만 앎 |
| 5 | KDD 전처리 vs 변환 | 전처리 = **잡음·결측·이상치** / 변환 = **차원 축소·변수 선택** |
| 6 | 하향식 vs 상향식 | 하향식 = 문제 **정의됨** / 상향식 = 문제 **불명확**, 데이터부터 |
| 7 | 시급성 vs 난이도 순서 | 시급성 **3→4→2** / 난이도 **3→1→2** |
| 8 | 정착형 vs 도입형 | 정착형 = **성숙도만** 높음 / 도입형 = **준비도만** 높음 |
| 9 | 집중형 vs 분산형 | 집중형 = 전담 조직 (업무 중복 가능) / 분산형 = 인력을 **현업 배치** |
| 10 | 층화 vs 군집 추출 | 층화 = 층마다 **일부** 추출 / 군집 = 군집 **통째로** |
| 11 | 구간 vs 비율척도 | 절대 0 **없음**(온도) / 절대 0 **있음**(몸무게) |
| 12 | 배반 vs 독립 | 배반 = 동시 불가 P(A∩B)=0 / 독립 = P(A∩B)=P(A)P(B) |
| 13 | 제1종 vs 제2종 오류 | 1종 = 참인 H0 **기각**(α) / 2종 = 거짓인 H0 **채택**(β) |
| 14 | 차분 vs 변환 | **평균** 불안정 → 차분 / **분산** 불안정 → 변환 |
| 15 | AR vs MA | AR → **PACF** 절단 / MA → **ACF** 절단 |
| 16 | 릿지 vs 라쏘 | 릿지 = L2, 0 안 됨 / 라쏘 = L1, **0 가능** |
| 17 | 정밀도 vs 재현율 | 정밀도 = 분모 **예측** 양성 / 재현율 = 분모 **실제** 양성 |
| 18 | 배깅 vs 부스팅 | 배깅 = 병렬·투표 / 부스팅 = 순차·**오답 가중치** |
| 19 | 계층적 vs K-means | 계층적 = **덴드로그램** / K-means = **K 미리 지정**, 이상값에 민감 |
| 20 | 시그모이드 vs 소프트맥스 | 시그모이드 = 이진 (0~1) / 소프트맥스 = **다중** (합 1) |

### 📝 시험 직전 1분 체크리스트
- [ ] p-value < 0.05 → 귀무가설 기각
- [ ] 제1종 오류 = α (참인 H0를 기각)
- [ ] R² = SSR/SST, 변수 유의성 = t검정, 모형 유의성 = F검정
- [ ] VIF > 10 → 다중공선성
- [ ] Lasso = L1 = 계수 0 가능 / Ridge = L2
- [ ] 정밀도 = TP/(TP+FP), 재현율 = TP/(TP+FN), 특이도 = TN/(TN+FP)
- [ ] ROC: x축 1−특이도, y축 민감도
- [ ] 지지도 P(A∩B), 신뢰도 P(A∩B)/P(A), 향상도 신뢰도/P(B)
- [ ] 향상도 = 1 → 독립
- [ ] 붓스트랩 OOB ≈ 36.8%
- [ ] AR → PACF 절단, MA → ACF 절단
- [ ] 오른쪽 꼬리(양의 왜도): 최빈값 < 중앙값 < 평균
