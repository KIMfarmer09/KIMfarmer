# ADsP (데이터분석 준전문가) 합격 준비 자료

> 이 폴더는 **ADsP 시험을 처음 준비하는 사람**을 위한 요약 노트 + 연습문제 + R 실습 파일 모음입니다.
> 코딩을 몰라도 합격할 수 있는 시험이니 걱정하지 마세요. 😊

---

## 0. 이 폴더 사용법 (VS Code 초보용)

1. VS Code를 켭니다.
2. 왼쪽 위 메뉴 **File(파일) → Open Folder(폴더 열기)** 를 누르고 이 저장소 폴더(`KIMfarmer`)를 선택합니다.
3. 왼쪽 파일 목록(탐색기)에서 `adsp` 폴더를 펼칩니다.
4. `.md` 파일(마크다운 문서)을 클릭한 뒤 **`Ctrl + Shift + V`** (맥은 `Cmd + Shift + V`)를 누르면
   글자·표·굵은 글씨가 **예쁘게 정리된 화면(미리보기)** 으로 볼 수 있어요.
   - 💡 원리: `.md`는 `#`, `**`, `|` 같은 기호로 서식을 적는 "메모장 문서"입니다. 미리보기는 그 기호를 해석해서 보여주는 기능이에요.
5. 연습문제의 정답은 **`▶ 정답 보기`** 를 클릭하면 펼쳐집니다(미리보기 화면에서).

## 2. 시험 한눈에 보기

> ⚠️ 시험 일정·응시료·세부 규정은 해마다 바뀔 수 있어요. 접수 전 반드시
> **데이터자격검정 공식 사이트(https://www.dataq.or.kr)** 에서 최신 공지를 확인하세요.

| 항목 | 내용 |
|---|---|
| 주관 | 한국데이터산업진흥원 (K-data) |
| 과목 | 1과목 데이터 이해 / 2과목 데이터 분석 기획 / 3과목 데이터 분석 |
| 문항 | 객관식 4지선다 50문항 (1과목 10 · 2과목 10 · 3과목 30) — 문항당 2점 |
| 시간 | 90분 |
| 합격 기준 | **총점 60점 이상** + **과목별 40% 이상** (하나라도 40% 미만이면 과락 = 불합격) |

### 합격 전략 (핵심!)

- 3과목이 **30문항(60점)** 으로 가장 큽니다. 여기서 절반 이상 맞히는 게 관건이에요.
- 1·2과목은 **암기형**이라 짧은 시간에 점수를 올리기 좋습니다. 여기서 각 7~8개 이상을 목표로!
- 목표 예시: 1과목 7개 + 2과목 7개 + 3과목 17개 = 31개 × 2점 = **62점 → 합격**
- 과락(40%) 기준: 1·2과목은 각 **4문항 이상**, 3과목은 **12문항 이상** 맞혀야 해요.

## 3. 4주 학습 계획 (하루 1~2시간 기준)

| 주차 | 할 일 |
|---|---|
| 1주차 | 1과목 전체 + 2과목 앞부분 읽기 → 연습문제 1·2과목 풀기 |
| 2주차 | 2과목 마무리 + 3과목 "통계 기초 ~ 가설검정" |
| 3주차 | 3과목 "회귀 ~ 데이터마이닝(분류·군집·연관)" + 계산 문제 반복 |
| 4주차 | 공식 사이트 기출문제/시중 문제집으로 실전 모의고사 2~3회 + 틀린 부분만 노트 복습 |

### 공부 요령
1. **처음엔 다 이해하려 하지 말고 끝까지 한 번 훑기** → 두 번째 읽을 때 이해가 붙습니다.
2. 각 노트의 **⭐ 표시**는 시험 단골입니다. 이것부터 외우세요.
3. 3과목 계산 문제(연관규칙, 혼동행렬)는 **손으로 직접** 풀어 보세요. 공식만 알면 무조건 맞히는 점수예요.
4. 틀린 문제는 "왜 틀렸는지" 한 줄로 적어 두면 시험 직전 복습용으로 최고입니다.
