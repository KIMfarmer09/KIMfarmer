- DB 특징: 통합·저장·공용·변화 / DW 특징: 주제 지향·통합·시계열·**비휘발**

- Soft Skill: 통찰력 있는 분석 · 설득력 있는 전달(시각화) · 다분야 협력
- 분석 주제: 최적화(둘 다 앎) · 솔루션(대상만) · 통찰(방법만) · 발견(둘 다 모름)
- CRISP-DM: 업무 이해 → 데이터 이해 → 데이터 준비 → 모델링 → 평가 → 전개

### 📝 시험 직전 1분 체크리스트
- [ ] p-value < 0.05 → 귀무가설 기각
- [ ] 제1종 오류 = α (참인 H0를 기각)
- [ ] R² = SSR/SST, 변수 유의성 = t검정, 모형 유의성 = F검정
- [ ] VIF > 10 → 다중공선성
- [ ] Lasso = L1 = 계수 0 가능 / Ridge = L2
- [ ] 정밀도 = TP/(TP+FP), 재현율 = TP/(TP+FN), 특이도 = TN/(TN+FP)
- [ ] ROC: x축 1−특이도, y축 민감도
- [ ] 지지도 P(A∩B), 신뢰도 P(A∩B)/P(A), 향상도 신뢰도/P(B)
- [ ] 향상도 = 1 → 독립
- [ ] 붓스트랩 OOB ≈ 36.8%
- [ ] AR → PACF 절단, MA → ACF 절단
- [ ] 오른쪽 꼬리(양의 왜도): 최빈값 < 중앙값 < 평균
