## 📖 오늘 공부할 내용

<sub>📘 1과목</sub>

### 1-1. 데이터의 유형
| 구분 | 설명 | 예시 |
|---|---|---|
| **정량적 데이터** | 숫자로 표현, 저장·분석이 쉬움 | 키, 온도, 매출액 |
| **정성적 데이터** | 말·글·그림 등 형태가 정해지지 않음, 분석이 어려움 | 설문 주관식 답변, SNS 글 |

### 1-2. 암묵지 vs 형식지 ⭐
- **암묵지**: 머릿속에 있어서 겉으로 드러나지 않는 지식 (예: 장인의 손맛, 김장 노하우)
- **형식지**: 문서·매뉴얼처럼 겉으로 드러나 공유 가능한 지식

**지식 전환 4단계 (SECI 모델, 노나카)** — 순서대로 외우기: **공 → 표 → 연 → 내**

| 단계 | 방향 | 뜻 |
|---|---|---|
| **공통화** (Socialization) | 암묵지 → 암묵지 | 같이 일하며 보고 배움 |
| **표출화** (Externalization) | 암묵지 → 형식지 | 노하우를 문서로 작성 |
| **연결화** (Combination) | 형식지 → 형식지 | 문서끼리 합쳐 새 문서 |
| **내면화** (Internalization) | 형식지 → 암묵지 | 문서를 읽고 내 것으로 체득 |

### 1-3. DIKW 피라미드 ⭐
아래에서 위로 갈수록 가치가 높아집니다.

| 단계 | 뜻 | 예시 |
|---|---|---|
| **D**ata (데이터) | 가공 전의 객관적 사실 | A마트 볼펜 100원, B마트 200원 |
| **I**nformation (정보) | 데이터를 가공해 **의미**를 도출 | A마트 볼펜이 더 싸다 |
| **K**nowledge (지식) | 정보를 구조화해 **내 행동**에 연결 | 가격이 싼 A마트에서 사야겠다 |
| **W**isdom (지혜) | 지식을 바탕으로 한 **창의적 아이디어** | A마트의 다른 물건도 쌀 것이다 |

### 1-4. 데이터베이스(DB)의 정의와 특징
- **정의**: 체계적으로 수집·축적하여 다양한 용도와 방법으로 이용할 수 있게 정리한 정보의 집합체
- **특징 4가지** ⭐ (통·저·공·변):
  - **통합된** 데이터 (중복 없음), **저장된** 데이터 (컴퓨터 저장매체), **공용** 데이터 (여럿이 함께 사용), **변화되는** 데이터 (계속 갱신)
- **DBMS**: DB를 관리하는 프로그램 (예: Oracle, MySQL) / **SQL**: DB에 질문(조회)하는 언어

### 1-5. 기업 내부 데이터베이스 ⭐
| 용어 | 한 줄 설명 |
|---|---|
| **OLTP** | 실시간 거래 처리 (예: 은행 입출금) — "기록" 중심 |
| **OLAP** | 다차원 분석 처리 — "분석" 중심 |
| **ERP** | 인사·재무·생산 등 **전사 자원**을 통합 관리 |
| **CRM** | **고객** 관계 관리 |
| **SCM** | **공급망**(원재료→생산→유통) 관리 |
| **BI** | 데이터를 리포트·대시보드로 보여줘 의사결정 지원 |
| **KMS** | 지식 관리 시스템 |
| **DW (데이터 웨어하우스)** | 분석용으로 모아둔 대형 창고 |
| **데이터 마트** | DW의 일부, 특정 부서용 작은 창고 |

**DW의 특징 4가지** ⭐: **주제 지향적**, **통합적**, **시계열성**, **비휘발성**(한 번 적재되면 잘 안 바뀜)

## ✅ 확인 문제

**1.** 다음 중 암묵지를 형식지로 바꾸는 지식 전환 단계는?
① 공통화 ② 표출화 ③ 연결화 ④ 내면화

<details><summary>▶ 정답 보기</summary>

**② 표출화** — 머릿속 노하우(암묵지)를 문서(형식지)로 꺼내 "표출"하는 단계. 순서: 공통화→표출화→연결화→내면화
</details>

**2.** "A마트 볼펜이 B마트보다 싸다"는 DIKW 중 어디에 해당하는가?
① Data ② Information ③ Knowledge ④ Wisdom

<details><summary>▶ 정답 보기</summary>

**② Information** — 두 가격 데이터를 비교해 **의미**를 도출했으므로 정보. "그럼 A마트에서 사야지"는 지식.
</details>

**3.** 데이터 웨어하우스의 특징이 **아닌** 것은?
① 주제 지향성 ② 통합성 ③ 휘발성 ④ 시계열성

<details><summary>▶ 정답 보기</summary>

**③ 휘발성** — DW는 **비휘발성**(한 번 적재된 데이터는 삭제·변경이 거의 없음)이 특징.
</details>
