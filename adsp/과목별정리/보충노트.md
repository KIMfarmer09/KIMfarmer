### 보-5. 확률 기초 · 베이즈 정리 ⭐⭐

**기본 공식**
- 여사건: P(A가 아님) = 1 − P(A)
- 덧셈: **P(A∪B) = P(A) + P(B) − P(A∩B)**
- 조건부확률: **P(B|A) = P(A∩B) / P(A)** ("A가 일어났을 때 B가 일어날 확률")
- 곱셈: P(A∩B) = P(A) × P(B|A)

**배반 vs 독립** ⭐ (자주 헷갈림!)
| | 뜻 | 식 |
|---|---|---|
| **배반** | **동시에 일어날 수 없음** (주사위 1과 2) | P(A∩B) = 0 |
| **독립** | 서로 **영향을 주지 않음** (동전과 주사위) | P(A∩B) = P(A) × P(B) |
> 확률이 0보다 큰 두 사건이 배반이면 **독립이 아니에요**. (A가 일어나면 B는 절대 안 일어나므로 영향을 줌)

**베이즈 정리** ⭐⭐ — "결과를 보고 원인의 확률을 거꾸로 구하기"
**P(A|B) = P(B|A) × P(A) / P(B)**

**예제**: 유병률 1%인 병. 검사는 환자의 99%를 양성으로, 정상인의 5%를 (잘못) 양성으로 판정. 양성이 나왔을 때 실제 환자일 확률은?
- 환자이면서 양성: 0.01 × 0.99 = 0.0099
- 정상이면서 양성: 0.99 × 0.05 = 0.0495
- 양성 전체: 0.0099 + 0.0495 = 0.0594
- **P(환자 | 양성) = 0.0099 / 0.0594 ≈ 0.167 (약 17%)**
> 💡 풀이 요령: **"해당 경우 ÷ 전체 경우"** 로 표를 그리듯 풀면 공식을 몰라도 풀려요.

**이항분포 계산**: n번 중 k번 성공할 확률 = **nCk × p^k × (1−p)^(n−k)**
- 예) 동전 3번 중 앞면 정확히 2번: 3C2 × 0.5² × 0.5 = 3 × 0.125 = **0.375**
- nCk = n! / (k!(n−k)!) → 3C2 = 3

**기댓값·분산 계산** ⭐
| X | 0 | 1 | 2 |
|---|---|---|---|
| P(X) | 0.2 | 0.5 | 0.3 |
- **E(X)** = Σ x·P(x) = 0×0.2 + 1×0.5 + 2×0.3 = **1.1**
- E(X²) = 0 + 1×0.5 + 4×0.3 = 1.7
- **Var(X) = E(X²) − [E(X)]²** = 1.7 − 1.21 = **0.49**

**분포별 평균·분산 공식**
| 분포 | 평균 | 분산 |
|---|---|---|
| 이항 B(n, p) | **np** | **np(1−p)** |
| 포아송 (λ) | **λ** | **λ** (평균 = 분산!) |

### 보-6. 정규분포 · 표본평균 · 공분산 ⭐

**표준화 (Z 점수)** ⭐: **Z = (X − 평균) / 표준편차** → 평균 0, 표준편차 1로 바꿈
- 예) 평균 70, 표준편차 10인 시험에서 90점 → Z = (90 − 70) / 10 = **2**

**정규분포 68-95-99.7 법칙**
- 평균 ± 1σ 안에 약 **68%**, ± 2σ 안에 약 **95%**, ± 3σ 안에 약 **99.7%**
- 예) Z = 2 이상 → 위쪽 꼬리 약 **2.5%** (정확히는 2.28%)

**중심극한정리** ⭐
- 표본 크기 n이 충분히 크면(보통 **30 이상**), 모집단 분포가 어떻든 **표본평균의 분포는 정규분포**에 가까워짐
- 표본평균의 평균 = μ, 표본평균의 표준편차(**표준오차**) = **σ / √n**
- 예) σ = 10, n = 25 → 표준오차 = 10 / 5 = **2**

**95% 신뢰구간** = 표본평균 ± **1.96** × σ/√n
- 예) 표본평균 50, σ = 10, n = 100 → 50 ± 1.96 × 1 → **(48.04, 51.96)**

**공분산 vs 상관계수** ⭐
| | 공분산 | 상관계수 |
|---|---|---|
| 의미 | 두 변수가 같이 움직이는 **방향** | 방향 + **강도** |
| 범위 | 제한 없음 | **−1 ~ +1** |
| 단위 | 측정 단위에 **영향 받음** (cm→m 바꾸면 값 변함) | 단위와 **무관** |
- 상관계수 = Cov(X,Y) / (σX × σY)
- **Var(X + Y) = Var(X) + Var(Y) + 2Cov(X,Y)** → 독립이면 Cov = 0이라 그냥 더하면 됨
- 독립이면 공분산 = 0. 하지만 **공분산 = 0이라고 독립은 아님** (비선형 관계 가능)

**표본분산은 n − 1로 나눔** (자유도). 모집단을 더 정확히 추정하기 위해서예요.

### 보-7. R 검정 결과 읽기 ⭐⭐

**① t검정 출력**
```
	Welch Two Sample t-test

data:  mpg by am
t = -3.7671, df = 18.332, p-value = 0.001374
alternative hypothesis: true difference in means between group 0 and group 1 is not equal to 0
95 percent confidence interval:
 -11.280194  -3.209684
sample estimates:
mean in group 0 mean in group 1 
       17.14737        24.39231 
```
| 확인할 곳 | 해석 |
|---|---|
| `Welch` | **등분산을 가정하지 않은** t검정 (등분산 가정이면 "Two Sample t-test") |
| `p-value = 0.001374` | 0.05보다 작음 → **두 집단 평균이 다르다** |
| `95 percent confidence interval` | 평균 차이의 신뢰구간에 **0이 포함되지 않음** → 역시 유의 |
| `mean in group …` | 각 집단 평균 (group 1이 더 큼) |

**② 분산분석(ANOVA) 출력**
```
             Df Sum Sq Mean Sq F value Pr(>F)    
Species       2  63.21  31.606   119.3 <2e-16 ***
Residuals   147  38.96   0.265                   
```
| 확인할 곳 | 계산·해석 |
|---|---|
| Df (집단) | 집단 수 − 1 = 3 − 1 = **2** |
| Df (Residuals) | 전체 n − 집단 수 = 150 − 3 = **147** |
| Mean Sq | **Sum Sq ÷ Df** (63.21 ÷ 2 = 31.606) |
| F value | **집단 Mean Sq ÷ 잔차 Mean Sq** (31.606 ÷ 0.265 ≈ 119.3) |
| Pr(>F) | 0.05보다 작음 → 적어도 한 집단 평균은 다름 |
- 어느 집단끼리 다른지는 **사후검정**(Tukey HSD 등)으로 확인

**③ 카이제곱 검정**
- 출력: `X-squared = …, df = …, p-value = …`
- **자유도 = (행 개수 − 1) × (열 개수 − 1)** ⭐ — 예) 3×4 표 → 2 × 3 = **6**
- 기대빈도가 5 미만인 칸이 많으면 경고가 뜨고, 이때는 Fisher 정확 검정을 고려

**④ 정규성 검정 (shapiro.test)**
- 귀무가설 = "정규분포를 따른다" → **p-value > 0.05 이면 정규성 만족**

### 보-8. 회귀분석 보충 ⭐

**더미 변수**: 범주가 **k개**면 더미 변수는 **k − 1개** (예: 봄·여름·가을·겨울 → 3개)

**잔차 그래프로 가정 확인** ⭐
| 그래프 모양 | 의미 |
|---|---|
| 0을 중심으로 **고르게 흩어짐** | 정상 |
| **깔때기** 모양 (점점 퍼짐) | **등분산성** 위배 |
| **곡선** 패턴 | **선형성** 위배 |
| Q-Q plot이 직선에서 벗어남 | **정규성** 위배 |

- R의 `plot(model)` 4개 그래프: Residuals vs Fitted(선형성·등분산), Normal Q-Q(정규성), Scale-Location(등분산), Residuals vs Leverage(**영향점** — **쿡의 거리**가 크면 영향점)
- **독립성** 검정: **더빈-왓슨(Durbin-Watson)** — **2에 가까우면** 자기상관 없음 ⭐

**R²의 함정**: 변수를 추가하면 **R²은 항상 커지거나 그대로** → 변수 수가 다른 모형 비교는 **수정된 R²** 사용

**로지스틱 회귀 출력 읽기** (예시 — 숫자는 설명용)
```
            Estimate Std. Error z value Pr(>|z|)
(Intercept)   12.040      4.510   2.670   0.0076 **
wt            -4.024      1.436  -2.801   0.0051 **
    Null deviance: 43.230  on 31  degrees of freedom
Residual deviance: 19.176  on 30  degrees of freedom
AIC: 23.176
```
- 선형회귀는 `t value`, 로지스틱은 **`z value`** 가 나옴
- wt 계수 −4.024 → wt가 1 증가하면 오즈가 **exp(−4.024) ≈ 0.018배** (= 약 98% 감소)
- Null deviance(변수 없는 모형) → Residual deviance(내 모형)로 **줄어든 만큼** 설명력이 있다는 뜻

**step() 변수 선택 출력 읽기** (예시 — 숫자는 설명용)
```
Start:  AIC=70.9
mpg ~ cyl + disp + hp + wt
       Df Sum of Sq    RSS    AIC
- disp  1     0.0     170.4  68.9
- cyl   1     ...      ...   69.5
<none>               170.4  70.9
- wt    1     ...      ...   80.2
```
- `- 변수` = 그 변수를 **뺐을 때**의 AIC. **`<none>`(그대로)보다 AIC가 작으면 빼는 게 좋음** → 여기선 disp 제거
- AIC가 더 이상 줄지 않으면 멈춤

### 보-9. 시계열 · 주성분분석 보충 ⭐

**시계열 추가 개념**
- **이동평균법**: 최근 n개 값의 평균으로 예측 (모든 값에 같은 가중치)
- **지수평활법** ⭐: **최근 값일수록 더 큰 가중치** (과거로 갈수록 지수적으로 감소). 평활 상수 α(0~1)가 클수록 최근 값을 중시
- **백색잡음**: 평균 0, 분산 일정, 자기상관 없음 → 모형의 잔차가 백색잡음이면 모형이 잘 맞은 것
- ARIMA 읽기: ARIMA(1,0,0) = AR(1) / ARIMA(0,0,1) = MA(1) / ARIMA(1,1,0) = 1번 차분 후 AR(1)

**PCA 출력 읽기** ⭐⭐
```
Importance of components:
                          PC1    PC2     PC3     PC4
Standard deviation     1.7084 0.9560 0.38309 0.14393
Proportion of Variance 0.7296 0.2285 0.03669 0.00518
Cumulative Proportion  0.7296 0.9581 0.99482 1.00000
```
| 행 | 해석 |
|---|---|
| Standard deviation | 각 주성분의 표준편차 (제곱하면 분산 = 고유값) |
| Proportion of Variance | 각 주성분이 설명하는 비율 → PC1 **73%** |
| Cumulative Proportion | 누적 → PC2까지 **95.8%** → **주성분 2개면 충분** |

**적재값(loadings) 읽기**
```
                PC1
Sepal.Length  0.521
Sepal.Width  -0.269
Petal.Length  0.580
Petal.Width   0.565
```
- PC1 = 0.521×Sepal.Length − 0.269×Sepal.Width + 0.580×Petal.Length + 0.565×Petal.Width
- 절댓값이 큰 변수(Petal.Length, Petal.Width)가 PC1에 **크게 기여**
- 주성분끼리는 **서로 상관이 없음(직교)**
- 변수 단위가 다르면 **표준화(scale = TRUE, 상관행렬 사용)** 후 PCA

### 보-10. 데이터마이닝 계산 모음 ⭐⭐

**① 거리 계산** — A(1, 2), B(4, 6)
| 거리 | 계산 | 값 |
|---|---|---|
| **유클리드** (직선) | √((4−1)² + (6−2)²) = √(9 + 16) | **5** |
| **맨해튼** (격자) | \|4−1\| + \|6−2\| = 3 + 4 | **7** |
| **체비셰프** (가장 큰 차이) | max(3, 4) | **4** |

**② 자카드 유사도** (범주형·집합) = **교집합 ÷ 합집합**
- A = {빵, 우유, 계란}, B = {빵, 우유, 버터, 잼} → 교집합 2개, 합집합 5개 → **0.4**
- 자카드 **거리** = 1 − 유사도 = **0.6**

**③ 엔트로피와 정보 획득**
- **엔트로피 = −Σ p × log₂p** (0이면 순수, 클수록 섞임)
  - 5:5 → **1** (최대로 섞임) / 10:0 → **0** (순수) / 8:2 → 약 **0.72**
- **지니 지수 = 1 − Σp²** (5:5 → 0.5 / 10:0 → 0)
- **정보 획득(Information Gain)** = 부모 불순도 − 자식 불순도의 **가중평균** → 클수록 좋은 분리
  - 예) 부모 5:5 (지니 0.5) → 왼쪽 4:0 (지니 0), 오른쪽 1:5 (지니 1 − (1/36 + 25/36) ≈ 0.278)
  - 자식 가중평균 = 0.4 × 0 + 0.6 × 0.278 ≈ 0.167 → 정보 획득 ≈ 0.5 − 0.167 = **0.333**

**④ 계층적 군집 연결법 계산** ⭐
- 거리: A–B = 2, A–C = 6, B–C = 5 → 가장 가까운 A, B를 먼저 묶음
- 묶음 (AB)와 C의 거리:
  - **최단연결**: min(6, 5) = **5**
  - **최장연결**: max(6, 5) = **6**
  - **평균연결**: (6 + 5) / 2 = **5.5**
- **덴드로그램 읽기**: 아래쪽에서 합쳐질수록 가까움. 높이 h에서 **가로로 잘랐을 때 만나는 세로선 개수 = 군집 수**

**⑤ K-means 진행 순서**: K개 초기 중심 선택 → 각 점을 **가장 가까운 중심**에 배정 → 중심을 **평균으로 다시 계산** → 변화가 없을 때까지 반복

**⑥ 인공신경망 계산** ⭐
- 입력 x = (1, 2), 가중치 w = (0.5, −0.2), 편향 b = 0.1
- z = 0.5×1 + (−0.2)×2 + 0.1 = 0.5 − 0.4 + 0.1 = **0.2**
  - ReLU → max(0, 0.2) = **0.2** / 계단 함수(0 기준) → **1** / 시그모이드(0)는 0.5
- **가중치 개수**: 입력 3 → 은닉 4 → 출력 1 이면 3×4 + 4×1 = **16개** (편향 포함하면 + 4 + 1 = 21개)

**⑦ 분류 기준값(cut-off) 변화** ⭐
- 기준값을 **낮추면** → 양성으로 더 많이 예측 → **민감도↑, 특이도↓**
- 기준값을 **높이면** → **민감도↓, 특이도↑** (둘은 트레이드오프)

**⑧ 향상도 곡선 계산**
- 향상도 = 해당 등급 반응률 ÷ 전체 반응률
- 예) 전체 반응률 5%, 상위 10% 고객 반응률 20% → 20 ÷ 5 = **4**

**⑨ 연관 분석 R 출력** (`inspect()`)
```
    lhs         rhs       support confidence coverage  lift count
[1] {빵}    => {우유}     0.30     0.50      0.60    1.25   3
```
- lhs = 조건(A), rhs = 결과(B), **coverage = A의 지지도**, count = 거래 수

**⑩ 기타 단골**
- 배깅은 **분산** 감소, 부스팅은 **편향** 감소에 효과
- 과대적합 방지: 가지치기, 정규화(릿지·라쏘), 드롭아웃, 교차검증, 조기 종료
- **불균형 데이터**(예: 사기 1%): 정확도만 보면 안 됨 → 재현율·F1 확인, 언더/오버샘플링(SMOTE)
